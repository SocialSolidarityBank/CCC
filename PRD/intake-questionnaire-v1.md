# CCC 인테이크·초기상담 질문지

> 첫 상담의 기준정보를 기록하고, 실무자의 판단과 후속 지원계획 수립에 활용합니다.

## 작성 원칙

- 모든 항목은 필수입니다.
- 확인되지 않았거나 당사자가 답변하지 않은 경우에는 빈칸 대신 **무응답**을 선택하거나 기입합니다.
- 개인정보는 상담과 지원에 필요한 범위에서만 기록합니다.

## 문서 구성

1. 상담 신청 및 기본정보
2. 현재 생활상황
3. 필요한 도움과 활용 가능한 자원
4. 상담 정리와 후속관리

## 2. 현재 생활상황

## 4. 상담 정리와 후속관리

상담 참여 여건, 추가 확인사항, 담당 실무자 의견과 다음 단계를 한 페이지에서 정리합니다.

### 4-1. 상담 참여 여건

- **참여 방해요인** *(필수)*
  - 선택값: 없음 / 근무시간 / 돌봄 부담 / 이동 어려움 / 건강 문제 / 연락 어려움 / 디지털 사용 어려움 / 비용 부담 / 복수 요인 / 기타 / 무응답
- **선호 상담 방식** *(필수)*
  - 선택값: 대면 / 전화 / 온라인 화상 / 방문 / 혼합 / 무응답

- **상세내용** *(필수)*
  - 작성 예시: 예: 평일 낮에는 돌봄 때문에 참여가 어렵고, 화요일 18시 이후 전화상담 가능

### 4-2. 추가 확인사항

| 추가 확인사항 | 필요한 이유 | 확인 방법 | 확인 예정 시점 |
|---|---|---|---|
| 예: 전체 채무 잔액 | 예: 채무조정 가능성 판단 | 예: 신용정보조회서 확인 | 예: 다음 상담 전 |
| 예: 의료급여 신청 여부 | 예: 치료비 부담 완화 검토 | 예: 주민센터 담당자 확인 | 예: 2026.08.05 |

### 4-3. 담당 실무자 의견

#### 담당 실무자 판단 및 다음 단계

- **긴급도** *(필수)*
  - 선택값: 일반 / 주의 / 긴급 / 즉시 개입 필요
- **주요 지원방향** *(필수)*
  - 선택값: 정보 제공 / 기관 연계 / 사례관리 진행 / 단기 집중지원 / 전문상담 의뢰 / 추가 사정 후 결정
- **담당 실무자 종합의견** *(필수)*
  - 작성 예시: 예: 채무 연체와 주거불안이 동시에 있어 우선순위가 높음. 다음 회차 전 신용정보조회서와 임대차계약서를 확인하고, 주민센터 긴급복지와 신용회복위원회 상담을 병행 연계할 필요가 있음.
