당사자 등록 화면 — 동의 블록(Y10)을 어떻게 할까

실제 앱 CSS(design/tokens.css + layout.tsx · wire-styles.ts)를 그대로 인라인해 그렸습니다 — 색·간격·테두리는 화면과 같은 값입니다. 폼 자체는 아직 고치지 않았습니다(코드 변경 0건).
보실 것은 동의 블록(가운데 상자)이 주변과 어떻게 어울리는가 하나입니다. 폭이 좁아 입력칸은 1열로 세웠지만 실제 화면은 2열입니다.

동의 블록만 크게

위 시안은 폼 전체라 상자 하나의 차이가 눈에 잘 안 잡힙니다. 같은 블록을 카드 안에 놓은 상태로 나란히 크게 그렸습니다.

현재 / 안 C

회색 테두리 1px · 흰 배경. 카드 안에 들어가면 카드와 배경색이 같아 상자가 테두리로만 존재한다.

동의 (항목별, 기본 미동의)

동의는 오프라인(종이·구두)으로 받고, 시스템에는 체크·일시·기록자만 남깁니다. 개인정보 수집·이용 동의는 등록에 반드시 필요하며, 녹음·텍스트 AI 는 미동의여도 등록이 진행됩니다.

긴급 등록은 사유와 함께 기록되고, 동의 보완 기한(등록일부터 14일)이 생깁니다.
