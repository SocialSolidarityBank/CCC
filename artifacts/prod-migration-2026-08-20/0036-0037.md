# 운영 D1 마이그레이션 적용 기록: 0036~0037 (2026-08-20)

2026-08-19 정책 검토 후속 구현 배치(PR #145~#149) 머지 직후 적용했다. 순서는 규칙대로
마이그레이션이 먼저다(`docs/ops.md` 운영 배포 절, 스키마 게이트).

## 적용 내역

| 마이그레이션 | 무엇 | 결과 |
| --- | --- | --- |
| 0036_text_work_lease.sql | 텍스트 일감 큐 임대: processing 상태·lease_owner·lease_expires_at·attempt_count·completed_snapshot_id (CCC-120) | 통과 |
| 0037_recording_result_transcript_quality.sql | 녹음 결과 커밋에 transcript_quality JSON 컬럼 + 불변 트리거 확장 (CCC-124) | 통과 |

적용 명령: `wrangler d1 migrations apply ccc --env production --remote`, 4개 명령 실행.
인증: wrangler OAuth 토큰 권한이 축소돼 있어 Infisical(bss-infra 머신 아이덴티티)의
`CLOUDFLARE_WORKERS_API_TOKEN`을 주입해 실행했다(값 출력 없음, CLAUDE.md §10 절차).
