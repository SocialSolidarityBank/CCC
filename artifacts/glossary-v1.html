프로젝트 안에서 같은 것을 같은 말로 부르기 위한 용어집입니다. 최근 들어온 문서(제품정의·인테이크·동의서 등)의 언어와 충돌하는 지점은 빨간 테두리와 배지로 표시했습니다 — 빨강은 이 프로젝트에서 위험 신호에만 쓰는 색입니다(D30).

프로젝트 이름

CCC Case Context Companion

케이스의 맥락(누적 기록·목표·리스크)을 상담사 곁에 붙여주는 동반 도구. 레포·패키지·Cloudflare 리소스 이름의 유래. 부르는 이름은 쎄쎄쎄 — 상담사와 참여자가 마주 앉아 리듬을 맞춰가는 도구라는 뜻.

케이스와 사람

케이스 Case

참여자 1명에 대한 지원·상담 전체를 묶는 단위. 인테이크로 열리고 종결로 닫힌다.

피하기: 사례 파일, 대상자

금전 지원 사업의 지원 대상이며 상담의 당사자. 2026-07-15 Q 확정(수혜자에서 변경 — 시혜적 뉘앙스를 피하고 코드·화면과 일치).

피하기: 익명 ID, 케이스 번호, 상담자 ID

PII 충돌 5

실명·연락처·이메일·계좌. 암호화된 금고(pii_vault)에만 존재. 내부 인증 사용자(관리자·상담사 전원)는 화면에서 실명 그대로 보고, 표시 화면 조회는 감사 기록된다(ADR-0009). 마스킹·가명화는 AI 처리·통계·외부 반출에만 적용.

피하기: 개인정보(범위가 더 넓어 혼동됨)

충돌: consent-draft-v0의 수집 항목은 "성명·연락처·이메일"뿐 — 계좌 누락. 인테이크 설계 v0는 생년월일·거주지역을 필수로 추가 예정(저장 위치 ⟦Q⟧ 미결). 동의 문안과 수집 실체를 법률 검토 전에 맞춰야 함.

담당자

참여자와 상담 관계를 맺고 해당 케이스의 상담·기록·PII를 책임지는 상담사. 배정된 케이스만 열람. 공동 담당 가능, 이관해도 과거 담당 이력은 남는다.

피하기: 매니저, 케이스 워커

시스템 관리자

계정·권한·서비스 설정·장애·보안을 관리하는 운영 역할. 케이스 내용(상담 기록·브리핑)은 기본적으로 열람 불가, 모든 케이스를 포괄하는 상담 권한도 없다.

피하기: 관리자(상담 권한으로 오해), 상담 관리자

배정 책임자

담당자 배정·공동 담당 추가·이관을 처리하는 역할. PII는 담당자와 동일하게 열람(ADR-0005), 상담 내용은 자신이 담당으로 배정된 케이스에서만.

피하기: 시스템 관리자, 전체 열람자

역할 겸임

한 사람이 시스템 관리자·배정 책임자·담당자를 함께 맡는 것. 역할은 합쳐져도 권한의 근거는 섞이지 않는다 — 상담 내용과 PII는 담당 배정된 케이스에서만 열린다.

피하기: 통합 관리자, 최고 관리자

배정 요청

배정 책임자가 상담사에게 케이스 담당을 제안한 상태. 수락 전까지 상담 내용·PII가 열리지 않는다. 1인 조직의 자기 배정은 즉시 수락 처리.

피하기: 배정 완료, 접근권한 부여

이관 수락

새 담당자가 케이스를 넘겨받겠다고 확인하는 행위. 이 시점부터 새 담당자의 접근이 시작되고 기존 담당자의 접근이 끝난다.

피하기: 배정 확인, 인수인계 완료

강제 이관

퇴사·장기 부재로 정상 수락 절차가 불가능할 때, 배정 책임자가 사유를 적고 담당을 바꾸는 예외 절차. 전건 감사와 당사자 알림을 남긴다.

피하기: 관리자 배정, 임의 이관

참여자 안내 확인

담당자 변경을 참여자에게 별도 연락으로 안내했는지 표시하는 체크. 시스템 안 동의 절차가 아니며, 체크하지 않아도 이관을 막지 않는다.

피하기: 참여자 승인, 전자 동의, 이관 허가

참여자 직접 접속

참여자 본인이 링크로 가입·로그인·동의서 작성을 하는 별도 화면 영역. 동의서 법률 검토 후 구현하며, 그 전까지 입력은 상담사가 대행한다(D26).

피하기: 참여자 포털(아직 없는 기능), 공개 가입

상담 관계

담당자와 참여자가 상담의 목적·역할·비밀보장 범위에 합의하고 함께 일하는 전문적 관계. 기록 접근 범위의 출발점.

피하기: 개인적 관계, 소유 관계

긴급 접근

시스템 관리자가 법적 요청·중대 안전사고·복구 불가능한 장애에 대응해 특정 케이스를 예외 열람하는 절차. 사유 입력·시간 제한·케이스 단위 제한·전건 감사·담당자 통지를 모두 충족해야 한다.

피하기: 관리자 권한, 전체 열람, 임시 관리자

기록

세션

참여자와의 대면 상담 1회에 대한 기록 단위. 현재 유일한 기록 종류(종류 세분화는 양식 확정과 함께 결정 — 인테이크 설계 v0에서 진행 중).

피하기: 상담 기록, 인터뷰, 면담 일지

수기 메모

상담사가 직접 작성한 세션 기록. 저장 즉시 공식 기록이며 승인 대상이 아니다(D5).

피하기: 노트, 상담 일지

AI 산출물

파이프라인이 만든 요약·분류 스키마 초안·대조 결과·감정 지표의 총칭. 승인 전까지 비공식 — 브리핑·통계·보고서에 나가지 않는다(R2).

피하기: AI 요약(전체를 가리킬 때), 초안(모호함)

승인

상담사가 대조 3종을 처리하고 AI 산출물을 공식 기록으로 확정하는 행위. 곧 정합성 검증이다.

피하기: 컨펌, 확정(단독 사용)

대조 3종

수기 메모와 녹취 기반 AI 정리를 맞대어 나오는 세 출력 — 메모에 없는 내용, 음성에 없는 내용, 미논의 목표.

피하기: 비교 결과, diff

목표와 신호

목표 Goal · 케이스 목표

인테이크에서 측정 가능한 문장으로 확정하는 상담 목표. 케이스당 활성 1~3개. 문구 수정 불가 — 종료+신설로만 바꾼다(D12). 세션 목표와 구별할 때는 "케이스 목표".

피하기: 과제, 플랜

세션 목표

피하기: 회차 목표, 목표(단독 — 케이스 목표와 혼동)

상담사가 이번 상담에서 직접 묻고 싶은 것. 상담 템플릿 구성의 입력이며, AI 생성 질문("오늘 확인할 질문")과 별개로 병행한다(ADR-0006).

피하기: AI 질문, 브리핑 질문

GAS 목표달성척도

목표마다 -2(악화)~+2(기대 초과) 5단계 점수. 점수는 상담사가 직접 매기고, AI는 근거 발언 발췌만 제안한다(D6).

피하기: 달성률, 점수(단독)

리스크 플래그

사전 정의된 고정 유형(4~6종)의 위험 신호. AI 제안은 전사 발언 인용 필수(사실 표시, 진단 아님) — 상담사가 맞음/틀림을 확인한다(D9).

피하기: 경고, 알림, 위험 태그

감정 지표

참여자 발화에서 자동 산출되는 숫자 점수와 추이. 문장형 감정 서술("불안하다")은 만들지도 저장하지도 않는다(R4).

피하기: 감정 분석 결과(문장 포함 오해), 정서 상태

데이터 구조
