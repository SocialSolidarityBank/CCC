## 인증 경로

`opsvc`로 Infisical 서비스 토큰을 프로세스 환경에만 주입하고, `infisical run --env=prod`가 `CLOUDFLARE_WORKERS_API_TOKEN`을 자식 프로세스에 넘겼다. 값은 출력하지 않았다.

## Time Travel 북마크 (적용 직전)

```
00000bed-00000000-000050e1-8738e9b76ec32e4f2432faa8a379a216
```

복구가 필요하면 `wrangler d1 time-travel restore ccc --env production --bookmark=<위 값>`이다.

## 실행

`CI=true wrangler d1 migrations apply ccc --env production --remote`
세 파일이 순서대로 적용됐고 각각 18, 29, (마지막 배치) 커맨드를 실행했다.
