## 적용 전 정적 확인

- **테이블·컬럼·데이터를 지우는 구문 0건.** DROP 은 4개 파일에 있으나 전부 트리거·뷰이고
  같은 파일에서 재생성된다(0014 트리거 1↔1 · 0022 1↔2 · 0025 뷰 2↔3 · 0026 트리거 1↔1)
- **기존 행을 고치는 UPDATE 0건**(트리거 본문 제외)
- **`purge_due` 를 채우는 마이그레이션 0건** — 보존 시계는 이미 적용된 0006 의 DB 트리거가
  케이스 종결 시에만 걸고, 운영에는 종결 케이스가 없다. 즉 적용이 파기 크론을 깨우지 않는다
