# 운영 D1 마이그레이션 0045~0048 적용 기록 (2026-09-05)

v0.6.0 운영 배포 전 선적용. 적용 대상은 `migrations/sqlite/` 기준 미적용 4건이다.
디렉터리 이동(`migrations/` → `migrations/sqlite/`, E3-1a)은 `wrangler.toml`의 `migrations_dir`가 함께 바뀌어
기존 0001~0044 적용 이력은 그대로 인식됐다.

| 파일 | 크기 | 명령 수 |
| --- | --- | --- |
| `0045_identity_revocation.sql` | 50,629B | 114 |
| `0046_sql_portability.sql` | 85,080B | 221 |
| `0047_timestamp_normalization.sql` | 64,890B | 156 |
| `0048_agent_jobs.sql` | 11,025B | 19 |

적용 명령: `wrangler d1 migrations apply ccc --env production --remote` (apps/api, `CI=true`).
인증: 이 맥의 wrangler OAuth 권한이 운영 D1에 미치지 않아(7403) Infisical `CLOUDFLARE_WORKERS_API_TOKEN`을
주입해 실행했다. 값 출력 없음(AGENTS.md §10 절차).
