Finding A01 | P2 | Conditional fail-open in the reused institution-admin guard
Evidence:
- gateway.ts:10636 invokes assertInstitutionAdmin before profile access.
- gateway.ts:1195-1200 checks current human identity and hasActiveHumanRoleAssignment('institution_admin').
- gateway.ts:1179-1184 normally requires an unrevoked institution_admin assignment scoped to actor.userId AND actor.orgId.
- gateway.ts:1165-1170 considers ANY error object with kind === 'syntax' a missing role-assignment table error, in addition to the specific SQLite missing-table message.
- gateway.ts:1185-1191 then returns actor.role === 'admin' instead of requiring the assignment.
- gateway.ts:10023-10048 verifies the current user's active legacy role, not its institution_admin assignment, so that check does not close the fallback.

Consequence:
If the assignment query fails with such an error after an active legacy-admin actor has been resolved, updateOrganizationProfile can proceed without proving an active IA assignment. A revoked IA or TA-only human represented by the legacy admin role is not rejected by that fallback. This is broader than a migration-only missing-table exception and conflicts with an unconditional 'active IA only' guarantee.

Reachability qualification:
This behavior is directly visible in the helper, but no live HTTP exploit is established by this review. resolveDirectoryActorByPrincipal at gateway.ts:9426-9436 queries the same assignment table without that fallback, so a table already missing during that identity resolution may fail before the request reaches PATCH. handleRequest also accepts an injected ActorResolver (request-handler.ts:2228-2234,2353). Whether a deployed resolver can reach the fallback was not investigated outside this authorized slice. Do not report this as an observed production TA escalation.

Suggested disposition:
Make this writer fail closed when IA assignment state cannot be read, or explicitly demonstrate that the legacy fallback is unreachable for supported profile requests. Do not silently broaden the shared helper migration behavior without its owner. A focused fault-injection contract case should keep profile values unchanged and return an error when the IA-assignment read fails; it should not fall back to a legacy admin claim.
