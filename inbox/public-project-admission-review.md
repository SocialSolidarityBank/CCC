# 공공사업 CCC 도입 확인 기록지

- 작성일: 2026-09-06
- 연결 결정: [ADR-0044](/Users/seongqkim/developer/PROJECTS/CCC-new/docs/adr/0044-public-project-admission-and-cloud-selection.md)
- 대상: 사회연대은행이 수행한다고 Q가 밝힌 경기극저신용자 지원사업
- 현재 판정: **미확인. 현행 계약·보안 부속서와 사업별 사용 승인 증빙 미확보**
- 주의: 공개자료는 수행 구조의 근거다. 현행 계약상의 법적 분류나 CSAP 의무, 특정 클라우드 허가를 증명하지 않는다.

## 1. 확인된 내용과 한계

| 구분 | 확인 내용 | 근거 | 한계 |
|---|---|---|---|
| 사용자 확인 | Q가 현재 기관에서 경기극저신용자 지원사업을 수행한다고 설명 | 2026-09-06 작업 요청 | 계약 연도와 신규 2.0·기존 상환관리 범위는 추가 확인 |
| 공개 공식자료 | 2021년 경기도 안내는 사회연대은행을 수행기관으로 명시하고 대출 심사·실행·상환 업무를 안내 | [경기도 2021년 2차 사업 안내](https://www.gg.go.kr/bbs/boardView.do?bsIdx=838&bIdx=26034771&page=1&menuId=1534&bcIdx=) | 과거 수행 근거이며 현행 계약 아님 |
| 공개 기관자료 | 사회연대은행이 경기복지재단과 사업 업무협약 체결 사실을 게시 | [사회연대은행 협약 소식](https://www.bss.or.kr/archive/business-news/경기복지재단과-경기-극저신용대출사업-업무/) | 업무협약이라는 제목만으로 법적 계약 형태를 확정하지 않음 |
| 공개 공식자료, 원문 확인 | 경기복지재단 공고 제2026-08호(2026-02-11) 선정 결과가 선정기관을 `(사)함께만드는세상`으로 명시 | [수행기관 선정 결과](https://ggwf.gg.go.kr/archives/70349)의 본문 이미지 직접 판독 | 2026년 선정의 직접 근거. 이후 계약 변경·해지 여부와 체결 조건까지 확인한 것은 아님 |
| 공개 공식자료, 첨부 확인 | 공고 제2026-05호(2026-01-29) 첨부 HWPX가 지방계약법 시행령 제43조 및 지방자치단체 입찰시 낙찰자 결정기준을 인용 | [평가위원 모집 공고](https://ggwf.gg.go.kr/archives/70198), 첨부 전체 본문 확인 | 낙찰자 선정 절차의 근거. 최종 민간위탁·용역 여부는 계약 원문 필요. 평가위원 보안각서는 사업의 개인정보 처리계약이 아님 |
| 공개 기관자료 | 2026년 경기극저신용대출 2.0은 대출과 상담 기반 금융·고용·복지 복합지원으로 안내 | [사회연대은행 2026년 2차 안내](https://www.bss.or.kr/business-apply/gyeonggi-low-credit-loan-recruit-2026-2nd/) | 모집 안내 게시만으로 2026년 수행계약 당사자 확정 불가 |
| 내부 탐색 | 현재 레포의 docs, PRD, inbox와 연결된 Notion에서 관련 용어로 검색 | 2026-09-06 문서 작업 | 현행 계약서·보안 부속서는 발견하지 못함. 기관 전체 문서보관소를 전수 조사한 것이 아님 |

추가 탐색은 웹검색어 변경, 재단 사이트 검색, 공식 게시판 인접글 링크 확인으로 진행했다. 선정 결과는 확보했으나 2026 수행기관 모집 원문, 제안요청서, 과업지시서와 체결 계약·보안 부속서는 확보하지 못했다. 평가위원 모집문의 `2026.2.10.(화)`는 선정평가 일정이며 사업 수행계약 기간으로 사용하지 않는다.

## 2. 반드시 확인할 항목

실제 계약서나 회신에 개인정보·계좌·서명·비공개 조건이 포함되면 공개 저장소에 원문을 넣지 않는다. 아래에는 안전한 식별자와 판정만 기록한다.

| 질문 | 현재 답변 | 확인할 문서 또는 담당 |
|---|---|---|
| 정확한 사업명, 연도, 신규 2.0 또는 기존 대출 사후관리 중 어느 범위인가? | 미확인 | 현행 계약·협약, 과업지시서, 사업 담당 |
| 계약 당사자와 법적 형식은 무엇인가? | 미확인 | 서명된 계약서와 근거 규정 |
| 해당 상담 기록의 개인정보처리자와 수탁·재수탁자는 누구인가? | 미확인 | 개인정보 처리위탁 부속서, 기관 개인정보 담당 |
| 지정된 업무 시스템이 있는가? CCC는 대체인가 보조인가? | 미확인 | 업무지침, 과업지시서, 발주·위탁 담당 |
| 별도 클라우드·AI 사용에 사전 승인 또는 재위탁 동의가 필요한가? | 미확인 | 보안특약, 처리위탁 조건 |
| 요구되는 CSAP 종류·등급·인증 범위와 CCC 자체 검토는 무엇인가? | 미확인 | 발주·위탁 주체 정보보안 담당 서면 확인 |
| 건강정보 등의 처리 근거와 신용정보 관련 추가 요건은 무엇인가? | 미확인 | 동의서, 법무 검토 |
| 외부 STT 원음 처리, 마스킹 뒤 LLM 처리와 국외 처리는 각각 가능한가? | 미확인 | 데이터 흐름도별 계약·법무·정보보안 확인 |
| 보관·반환·파기와 사업 종료 후 사후관리 조건은 무엇인가? | 미확인 | 계약·기록관리 지침 |
| 네이버 공공기관용 가입 자격, 계정 소유자, 비용과 운영지원 책임은 누구에게 있는가? | 미확인 | 공급자 영업 확인과 견적, 기관 계약 담당 |

## 3. 처리 경로별 판정

아래 후보는 운영 승인이나 이미 구축된 상태를 뜻하지 않는다. `확인 완료`를 기록하려면 실제 상품·기능·리전·보관·계약 버전과 승인 범위가 일치해야 한다.

| 경로 | 확인 대상 | 상태 | 증빙 식별자·버전 | 확인자·일자 | 남은 조건 |
|---|---|---|---|---|---|
| 업무 DB | Supabase 서울 또는 별도 승인 후보 | 미확인 | 미수령 | 미지정 | 사업별 저장 허가·인증 요구 |
| 인증·업무 API | Supabase Auth/Edge 또는 대체 실행기 | 미확인 | 미수령 | 미지정 | 실행 위치·계정·로그 경계 |
| 원음 임시 저장 | 실제 AudioStore | 미확인 | 미수령 | 미지정 | 계약상 원음 보관과 D85 삭제 증거 |
| 로컬 STT | 기관 처리 Agent | 미확인 | 미수령 | 미지정 | 수집 근거·엔진 승인·장비 운영 |
| 외부 STT | 선택한 정확한 상품·API | 미확인 | 미수령 | 미지정 | 원음 처리·재위탁·리전·삭제 |
| 외부 LLM | OpenAI API의 실제 모델·기능 | 미확인 | 미수령 | 미지정 | 마스킹 잔여 정보·국외 처리·로그 보관 |
| 로그·백업·원격지원 | 운영 공급자와 재수탁자 | 미확인 | 미수령 | 미지정 | 열람자·보관 국가·복구·종료 후 삭제 |

## 4. 회신을 받을 때 기록할 것

- 사업 범위 확인 담당: 미지정
- 개인정보·법무 확인 담당: 미지정
- 발주·위탁 주체의 정보보안 확인 담당: 미지정
- 운영·장애 대응 담당: 미지정
- 확인 완료 목표일: 미정. 해당 사업 실데이터 투입 이전
- 계약 문서 식별자·버전: 미수령
- 승인 문서 식별자·버전: 미수령
- 승인 대상 사업·모드·처리 경로: 미확인
- 예산 승인과 운영지원 계약: 미확인
- 조건부 승인 시 남은 조건과 이행 증거: 미확인
- 기존 LG1~LG3와 연결할 위치: SG14에서 정의 필요
- 실데이터 도입 최종 판정: 미확인

구두 답변은 참고로만 남기고 최종 판정은 권한 있는 담당자의 서면 근거로 확인한다. Q가 제품 방향을 승인하더라도 위탁 주체나 기관 법무의 승인을 대신하지 않는다.

## 5. 지금 가능한 작업과 보류할 작업

- 계속: 합성 데이터 개발, 세 모드 계약 테스트, read-only plan, 서비스별 데이터 흐름과 비용 산정, 승인 없이 외부 제출하지 않는 문의자료 준비
- 보류: 해당 사업 실데이터 신규 투입, 이전, 원음 업로드, 미승인 외부 AI 활성화와 운영 적합성 표기
- 별도 승인: 네이버로 공급자 전환, 새로운 인증·저장 어댑터, STT·LLM 변경, 유료 자원 생성, 공급자 계약 체결
- 이번 문서 작업으로 하지 않은 것: 계약 체결·발주처 문의·운영 설정 변경·데이터 이동·GitHub 또는 Linear 게시

## 6. 법적 구분을 위한 참고

- [서울특별시 행정사무의 민간위탁에 관한 조례](https://www.law.go.kr/LSW/ordinInfoP.do?ordinSeq=2100007): 사무의 민간위탁 개념 참고. 경기도 사업에 이 조례가 직접 적용된다는 뜻은 아님
- [개인정보 보호법 제26조](https://www.law.go.kr/LSW//lsLawLinkInfo.do?chrClsCd=010202&lsId=011357&lsJoLnkSeq=900079061&print=print): 개인정보 처리위탁과 재위탁 검토
- [KISA CSAP 안내](https://www.kisa.or.kr/1050603): 제공하는 클라우드서비스의 인증. 개별 사업의 적용 판정은 계약과 현행 기준으로 별도 확인

원문 증빙이 확보되면 이 기록지의 해당 행만 갱신하고 ADR-0044의 재검토 조건에 따라 판정한다. 공급자 변경이 필요하다는 결과가 나와도 자동 배포하지 않는다.
