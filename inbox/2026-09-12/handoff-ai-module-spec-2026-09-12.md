# 릴레이어 AI 모듈 정의서 (핸드오프)

- 작성일: 2026-09-12
- 범위: 상담 전 톺아보기, 당사자 정보(상담 기록, 경과 리포트, 목표와 계획 탭), AI 초안 검토 화면에서 AI가 만들어 주는 모든 항목
- 성격: 설계 정의서이자 작업 지시서다. 코드 대조는 하지 않았다. 코드와 맞춰 볼 항목은 8장에 모았다.
- 쓰임: 다음 세션이 이 문서에서 티켓을 잘라 개발 에이전트에게 넘기고, 2장의 결정을 ADR로 옮긴다. 에이전트에게는 이 문서 전체가 아니라 해당 모듈 절과 3장, 4장만 붙인다.
- 함께 볼 문서: CCC_15초페이지_전체리포트_정의.md와 팀 스킬 두 개(ccc-counseling-cards, ccc-full-report). 이 정의서는 그 셋이 정한 카드와 두 결과물을 화면 전체로 넓힌 것이다. 그 셋과 달라지는 점은 4-3에 모았다. 그 밖에 릴레이어 1차 점검(2026-09-11), handoff-post-completion-questions-2026-09-12(A01~A05, A07, A09, A12, P04), handoff-goal-model-review-2026-08-09.
- 용어: 화면 이름은 명사, 버튼은 짧은 동사, 화면 문구는 해요체. 카드 종류는 정의 문서의 이름을 그대로 쓴다(사실, 확인할 것, 약속한 일, 판단과 평가).

## 1. 한 줄 요약

상담 기록을 카드로 잘게 쪼개 두고, 화면마다 필요한 카드만 골라 붙인다. AI는 카드를 만들고, 맞대어 보고, 제안한다. 판단과 닫기는 사람이 한다. 사람은 제안에 일일이 답하지 않아도 되고, 틀린 것만 고친다.

---

## 2. 이번에 확정한 결정 (ADR 후보)

| 번호 | 결정 | 내용 |
|---|---|---|
| D-A1 | 구조 | 화면 항목마다 AI 지시문을 두지 않는다. 카드 창고 하나, 대조 3종, 조립 규칙으로 만든다. |
| D-A2 | 오늘 물어볼 것의 세 묶음 | 정보의 종류로 나눈다. (지난 회차에 확인하기로 한 것) (아직 결과가 없는 약속) (서로 다르게 적힌 것) |
| D-A3 | 주제 | 미리 정하지 않는다. AI가 원문에서 주제를 찾아 붙인다. 같은 사례 안에서는 이미 쓴 주제 이름을 다시 쓴다. 오늘 상담 기록의 9개 생활영역 칸은 실무자가 손으로 고르는 별도 칸으로 남고, AI 주제 찾기의 기준으로 쓰지 않는다. |
| D-A4 | 녹음-메모 대조의 표시 | "메모에 있는데 녹음에 없음"은 조용히 표시한다. 녹음 근거가 있는 문장에만 표시를 달고, 없는 문장에는 아무것도 달지 않는다. 목록, 개수, 경고, 통계로 만들지 않는다. |
| D-A5 | 번호 가명 | 마스킹 v2 앞에 넣는다. 같은 사람과 기관은 사례 안에서 늘 같은 번호("[인명1]", "[기관1]"). 번호는 사례 단위다. |
| D-A6 | 판단 원칙 | 애매하면 판단하지 않는다. 판단과 닫기는 사람, AI는 제안. |
| D-A7 | 응답 원칙 | AI 제안은 응답을 요구하지 않는다. 답하지 않아도 아무것도 막히지 않는다. 사람은 틀린 것만 고친다. 회차 AI 초안의 승인(회차당 한 번, D71)만 예외다. |

## 3. 모든 모듈이 따르는 규칙

1. 카드가 없으면 출력도 없다. 화면의 모든 문장에 회차 번호와 원문 인용이 달린다.
2. 판단하지 않는다. 진단, 누가 맞는지, 담당과 기한, 자동 완료, 위험 등급 매기기는 없다.
3. 대조 결과가 비어 있으면 세 상태 중 하나로 이유를 쓴다. 확인함(해당 없음) / 확인하지 못함(이유) / 확인 중. 이유 없는 "없음"은 금지다. 리포트에서 재료가 없는 섹션은 통째로 뺀다(정의 문서 원칙). 세 상태 문구는 대조 결과(M4, M5, M6)와 위험 신호(M11)에 적용한다.
4. 응답을 요구하지 않는다. 제안은 옆에 붙고, 무시해도 업무는 진행된다. AI가 "정리된 것 같다"고 본 항목은 지우지 않고 아래 구역으로 내린다. 틀렸으면 사람이 다시 올린다.
5. 개수를 억지로 맞추지 않는다. 목록(불일치, 약속 추적)은 다 보여 주고, 제안 질문만 위 3개를 보이고 "N건 더"를 알린다. 위험 관련은 항상 맨 위다.
6. 사람이 승인한 카드만 톺아보기와 리포트의 재료다. 승인 전 초안 카드는 상담 기록 탭 안의 그 회차에서만 보인다.
7. 밖으로 나가는 것은 가림을 거친 사본뿐이다. 상담 기억(ADR-0046)은 카드가 아니며, 그림자 모드인 동안 어떤 모듈의 근거도 될 수 없다.
8. 낙인을 붙이지 않는다. "반복 불이행" 같은 딱지 대신 회차 이력만 나열한다.
9. AI 글쓰기가 들어가는 모듈마다 정답표를 따로 둔다. 구조 검사(인용이 원문에 있는가)와 의미 검사(맞게 찾았는가)를 따로 보고한다(A07).

## 4. 카드의 생김새

카드는 모든 모듈의 공통 재료다. 상담 원문을 한 장에 한 가지씩 적은 포스트잇이라고 보면 된다.

### 4-1. 카드 한 장의 칸

| 칸 | 뜻 | 예 | 비고 |
|---|---|---|---|
| 카드 번호 | 사례 안에서 고유한 번호 | C-0042 | 스킬의 card_id |
| 사례, 회차 번호, 상담일 | 어느 사례의 어느 회차, 언제 | 3회차, 2026-08-20 | 회차 순서는 입력한 날이 아니라 상담한 날 |
| 출처 | 어디서 왔나 | 수기 메모 / 녹음 전사 / 첫 상담 기록 | 새 칸 |
| 화자 | 누가 한 말인가 | 실무자 / 당사자 | 스킬의 speaker |
| 원문 인용 | 원문 문장 그대로(가림 사본 기준) | "다음 주까지 소득 서류를 내겠다고 함" | 스킬의 content |
| 종류 | 네 가지 중 하나 | 약속한 일 | 사실 / 확인할 것 / 약속한 일 / 판단과 평가 |
| 행위자 | 약속한 일에만. 누가 하기로 했나 | 당사자 / 실무자 / 기관 | 새 칸. 화자와 다르다(적은 사람과 하는 사람) |
| 기한 | 원문에 있을 때만 그대로 | 상담일 +7일 | 새 칸. 추정하지 않는다 |
| 주제 | AI가 찾은 주제 이름, 여러 개 가능 | 채무, 소득 증빙 | 스킬의 category를 대체(D-A3) |
| 목표 연결 | 닿는 장기목표, 단기목표. 없으면 빈 칸 | 단기목표 2 | 새 칸 |
| 인물, 기관 | M1이 붙인 번호 | [인명1], [기관2] | 새 칸 |
| 승인 상태 | 초안 / 승인됨 | 승인됨 | 새 칸 |

### 4-2. 카드 사이의 연결

| 연결 | 누가 만드나 | 뜻 |
|---|---|---|
| 같은 내용 | M2 | 같은 회차의 수기 카드와 녹음 카드가 같은 말을 한다 |
| 결과 | M2(짝 찾기) | 약속한 일이나 확인할 것에 대한 뒤 회차의 사실. 했다 / 못 했다 / 필요 없어졌다 세 가지 |
| 갱신 | M2(짝 찾기) | 같은 약속을 뒤 회차에서 다시 약속함. 항목 하나로 유지 |
| 불일치 쌍 | M5 | 같은 주제의 사실 카드 둘이 서로 다른 값을 말한다 |
| 위험 신호 | M11 | 위험 표시 유형에 해당한다는 제안 |

### 4-3. 팀 스킬 문서(ccc-counseling-cards, ccc-full-report)와 달라지는 점

1. 분류(category) 6개 고정을 없애고 주제를 자유롭게 찾는다(D-A3). 스킬이 "지원사업 연계 이력" 분류에 기대던 04 자원연계는 [기관N] 번호로 카드를 찾는 방식으로 바꾼다.
2. 새 칸이 생긴다. 출처, 행위자, 기한, 목표 연결, 인물과 기관 번호, 승인 상태.
3. 새 연결이 생긴다. 결과, 갱신. 스킬의 "약속-결과 불일치" 유형은 M5(불일치)가 아니라 M6의 "못 했다" 결과 연결로 다룬다.
4. 빈 항목 처리를 둘로 나눈다. 리포트는 스킬대로 항목을 뺀다. 대조 결과(M4, M5, M6, M11)는 세 상태 문구를 쓴다.
5. 이름을 맞춘다. "15초 페이지" → "상담 전 톺아보기", "미해결 액션" → "남은 할 일"(등록된 것)과 "약속 추적"(카드에서 온 것), "대목표" → 등록된 장기목표(없으면 첫 상담 기록의 지원욕구와 지원방향을 참고로 표시).
6. 그대로 유지한다. 확신이 낮으면 카드를 만들지 않는다(안 만드는 쪽이 잘못 만드는 쪽보다 낫다). 확인할 것은 "확인하기로 함" 같은 명시적 문구가 있을 때만 만든다. 후속 확인이 필요해 보이는 판단과 평가 카드는 약속 추적에 넣지 않고 회차 요약에만 녹인다.

## 5. 모듈 정의

모듈은 네 층이다. 바탕(M1, M2), 색인(M3), 대조(M4, M5, M6), 조립(M7~M11). 각 모듈은 여덟 항목으로 적는다. 하는 일 / 입력과 출력 / 규칙 / 하지 않는 것 / 비었을 때 문구 / AI가 필요한 부분 / AI 꺼진 기관 / 시험.

"글쓰기 AI"는 글을 읽고 쓰는 AI(LLM)를 말한다. "규칙"은 AI 없이 정해진 대로 골라내는 것을 말한다.

### M1 가림

- 하는 일: 바깥 AI로 나가기 전에 개인정보를 가린다. 화면에 보이는 결과물은 없다.
- 입력과 출력: 입력은 회차 원문(수기 메모, 녹음 전사, 첫 상담 기록, 목표 문장). 출력은 가린 사본과 번호 대응표(사례 안에서 [인명1]이 누구인지 적은 표).
- 규칙: 같은 사람과 기관은 사례 안에서 늘 같은 번호(D-A5). 번호는 사례 단위다. 사업이 둘이면 번호도 따로 매긴다. 대응표는 금고와 같은 등급으로 보호하고 파기 때 함께 지운다. 날짜는 연월로 자르지 않고 "상담일 +N일"처럼 상대 날짜로 바꿔 기한 간격을 지킨다(S6 v2 규격 수정 필요). 짧은 목표 문장을 가림 품질 검사에 넣는다(8월 검수).
- 하지 않는 것: 관계 이름 붙이기([가족1], [채권자1])는 이번 범위 밖이다. 번호만 붙인다.
- 비었을 때 문구: 해당 없음.
- AI가 필요한 부분: 이름 찾기 모델과 규칙. 글쓰기 AI는 아니다.
- AI 꺼진 기관: 원문이 밖으로 나가지 않으므로 가림도 없다.
- 시험: 회차를 넘어 같은 사람이 같은 번호를 받는 비율. 짧은 목표 문장 가림 성공률. 기관 이름이 새는 비율.

### M2 카드 추출

- 하는 일: 회차 원문을 네 종류 카드로 쪼갠다. 첫 상담 기록도 그냥 1회차로 똑같이 쪼갠다.
- 입력과 출력: 입력은 가린 사본과 "이 사례에서 아직 결과가 없는 약속과 확인할 것 목록"(짝 찾기용). 출력은 카드(4-1)와 연결(같은 내용, 결과, 갱신).
- 규칙: 카드 하나에 주장 하나. 원문에 없는 것은 만들지 않는다. 확신이 낮으면 만들지 않는다. 확인할 것은 "확인하기로 함" 같은 명시적 문구가 있을 때만 만든다. 약속한 일에는 행위자와 원문 기한을 적는다. 같은 회차에 수기와 녹음이 같은 말을 하면 카드 둘을 만들고 "같은 내용"으로 잇는다. 새 카드가 열린 약속의 결과(했다, 못 했다, 필요 없어졌다)나 갱신(다시 약속)이면 그 연결을 단다. 짝 찾기는 카드를 만들 때 한 번에 한다. AI에게 그 회차 원문과 열린 약속 목록을 함께 주면 된다.
- 하지 않는 것: 담당과 기한 추정. 요약. 후속 확인이 필요해 보이는 판단을 확인할 것으로 승격.
- 비었을 때 문구: 원문이 없거나 짧음 → "이 회차는 기록이 짧아 카드를 만들지 못했어요".
- AI가 필요한 부분: 글쓰기 AI.
- AI 꺼진 기관: 카드 없음. 회차 단위 구조값(위기도, 할 일, 생활영역)만 있다.
- 시험: 정답표 대비 놓친 카드 수(재현율), 지어낸 카드 수(정밀도), 인용이 원문에 있는지(구조), 결과와 갱신 연결의 정확도.

### M3 꼬리표

- 하는 일: 카드마다 주제, 목표 연결, 인물과 기관 번호를 단다.
- 입력과 출력: 입력은 카드, 이 사례에서 이미 쓴 주제 이름 목록, 등록된 장기목표와 단기목표. 출력은 카드의 주제 칸과 목표 연결 칸.
- 규칙: 주제는 AI가 원문에서 찾는다. 미리 정한 목록은 없다(D-A3). AI에게 그 회차 원문과 "이 사례에서 이미 쓴 주제 이름 목록"을 함께 주고, 같은 뜻이면 이미 쓴 이름을 다시 쓰고 정말 새로우면 새 이름을 만들게 한다. 주제 이름은 명사 2~6글자(예: 채무, 주거, 자녀 교육). 카드 하나에 주제 여러 개 가능. 목표 연결은 뚜렷이 닿을 때만 달고 아니면 빈 칸으로 둔다. 실무자는 주제 이름을 바꾸거나 합칠 수 있고, 바꾼 것이 우선이다. 바꾸기는 선택이지 의무가 아니다.
- 하지 않는 것: 억지 목표 연결. 9개 생활영역을 AI 주제로 쓰기.
- 비었을 때 문구: 해당 없음(카드마다 주제는 최소 하나).
- AI가 필요한 부분: 주제 찾기와 목표 연결은 글쓰기 AI. 붙인 뒤 골라 모으기는 규칙.
- AI 꺼진 기관: 오늘 상담 기록에서 실무자가 고른 9개 생활영역이 회차 단위 주제 역할을 한다. 카드 단위 주제는 없다.
- 시험: 같은 사례를 두 번 돌렸을 때 주제 이름이 같은 비율(안정성). 사람이 붙인 주제와 일치율. 회차가 늘수록 주제 수가 계속 늘기만 하는지(파편화).

### M4 녹음-메모 대조

- 하는 일: 같은 회차의 녹음 카드와 수기 카드를 맞댄다.
- 입력과 출력: 입력은 한 회차의 카드와 "같은 내용" 연결. 출력 1은 녹음에는 있는데 메모에 없는 내용 목록("메모에 빠진 발언"). 출력 2는 메모 문장 중 녹음 근거가 있는 것에 다는 작은 표시.
- 규칙: 출력 1은 AI 초안 검토 화면에 보이고, 실무자가 원하면 메모에 옮겨 적는다. 옮기지 않고 승인해도 녹음 출처 카드로 남는다. 톺아보기의 기록 간 대조에는 "지난 회차 녹음에는 있었지만 메모에 없던 내용 N건"으로 개수만 보인다. 출력 2는 조용히 한다(D-A4). 근거 있는 문장에만 표시하고 없는 문장에는 아무것도 달지 않는다. 목록, 개수, 경고, 통계, 관리자 화면에 모으지 않는다.
- 하지 않는 것: 메모가 틀렸다는 표현. 실무자 평가 자료로 쓰기.
- 비었을 때 문구: 녹음 없음 → "이 회차는 녹음이 없어 메모와 대조하지 않았어요". 전사 품질 낮음 → "녹음 상태가 좋지 않아 일부만 대조했어요". 확인했는데 없음 → "메모에 빠진 내용은 없어요".
- AI가 필요한 부분: 글쓰기 AI(같은 내용인지 판정).
- AI 꺼진 기관: 없음. 상태 문구만 보인다.
- 시험: 정답표에 "말했는데 안 적힌 것"을 심어 두고 찾는 비율. 같은 내용을 다른 내용으로 잘못 가르는 비율.

### M5 회차 간 불일치

- 하는 일: 같은 주제의 사실 카드끼리 비교해 값, 시점, 상태가 다른 쌍을 나란히 보여 준다.
- 입력과 출력: 입력은 승인된 사실 카드 중 같은 주제인 것(핵심 지표 숫자는 미리 뺀다). 출력은 불일치 쌍(카드 둘, 종류, 위험도).
- 규칙: 정의 문서와 스킬 그대로. 표현만 다른 것은 뺀다. 누가 맞는지 판단하지 않는다. 개수 제한 없이 다 보여 주되 위험도 높은 주제(채무 금액, 중복 지원) 먼저. 판단과 평가 카드는 비교하지 않는다. 뒤 회차에서 실무자가 "확인함", "정정함"처럼 명시적으로 적은 새 사실 카드가 나오면 "정리된 것 같아요" 구역으로 내린다(지우지 않음). 실무자는 원하면 [확인함]으로 내릴 수 있다.
- 추가 규칙: 신용점수, 부채총액처럼 매 회차 바뀌는 숫자는 불일치가 아니라 변화다. M9 핵심 지표에 넣고 여기서는 뺀다. 노출 범위는 A01 결정을 따른다.
- 하지 않는 것: 어느 쪽이 맞는지 고르기. 정상적인 변화를 불일치로 부르기.
- 비었을 때 문구: 사실 카드가 한 회차분뿐 → "비교할 이전 기록이 없어요". 확인했는데 없음 → "N회차까지 비교했고 서로 다른 내용은 없어요".
- AI가 필요한 부분: 글쓰기 AI.
- AI 꺼진 기관: 없음. 상태 문구만 보인다.
- 시험: 심어 둔 불일치를 찾는 비율. 정상 변화를 불일치로 잘못 잡는 비율.

### M6 약속 추적

- 하는 일: 약속한 일과 확인할 것 카드 중 뒤 회차에 결과가 없는 것을 모은다. 릴레이어의 핵심 차별점을 화면에 올리는 자리다.
- 입력과 출력: 입력은 승인된 약속한 일, 확인할 것 카드와 결과, 갱신 연결(M2가 붙인 것), 등록된 할 일. 출력은 두 구역의 목록. "아직 결과 기록이 없는 약속"과 "결과 기록이 있는 약속".
- 규칙: 짝 찾기는 바로 다음 회차만이 아니라 뒤 회차 전부를 본다. 결과가 없으면 열린 채로 둔다. 몇 회차가 지나도 자동으로 닫지 않는다. 각 항목에 "N회차, M회 전"을 붙이고 원문 기한이 지났으면 표시한다. 정렬은 위험 관련 맨 위 고정, 나머지는 오래된 순. 갱신된 약속은 항목 하나로 유지하고 "3회차 약속, 5회차에 다시"처럼 이력만 붙인다. 결과 연결이 생기면 "결과 기록이 있는 약속" 구역으로 내린다. 지우는 것은 실무자만 한다(D-A7). 버튼은 선택이다. [해결됨] [해당 없음] [숨기기] [할 일로 등록]. 열린 항목이 10건을 넘으면 "오래된 항목 N건 한 번에 정리하기"를 띄운다. 등록된 할 일은 규칙(기한 지남, 미완료)으로 같은 목록에 들어가고, 카드에서 온 약속은 "아직 할 일로 등록하지 않은 약속"으로 구분해 보인다.
- 하지 않는 것: 담당과 기한 추정. 자동 완료. 자동 삭제. "반복 불이행" 딱지. 후속 확인이 필요해 보이는 판단과 평가 카드를 넣기.
- 비었을 때 문구: 확인했는데 없음 → "결과가 없는 약속은 없어요". 승인된 카드 없음 → "승인된 기록이 없어 약속을 찾지 못했어요".
- AI가 필요한 부분: 결과와 갱신 연결은 M2의 글쓰기 AI. 목록 만들기와 정렬은 규칙.
- AI 꺼진 기관: 등록된 할 일만.
- 시험: 엘루전 테스트(열린 목록에 없는 카드 중 표본을 사람이 다시 봐서 놓친 비율을 잰다). 심어 둔 약속-결과 쌍의 연결률. 갱신을 새 약속으로 잘못 만든 비율.
- 9월 18일 판: 읽기 전용. 버튼 없이 목록과 "몇 회 전"만 보인다.

### M7 회차 요약

- 하는 일: 가장 최근 회차에서 새로 나온 사실과 약속만 200자 안에 적는다.
- 입력과 출력: 입력은 그 회차의 승인된 카드와 꼬리표, 이전 회차 카드(반복 걸러내기용). 출력은 200자 안의 글.
- 규칙: 정의 문서 그대로. 이전에 나온 내용은 반복하지 않는다. 약속이 있으면 반드시 넣되 가장 중요한 1~2개. 위험 관련은 맨 위. 순서는 위험, 목표에 닿는 것, 그 밖의 것. 후속 확인이 필요해 보이는 판단과 평가 카드는 여기에 녹인다. 한 주제(예: 채무)만으로 매번 채우지 않는다.
- 하지 않는 것: 목표와 무관하다고 새 위험을 빼기. 판단 추가.
- 비었을 때 문구: 승인된 카드 없음 → "지난 회차 기록이 아직 승인되지 않았어요". 새 내용 없음 → "지난 회차에 새로 나온 내용은 없어요".
- AI가 필요한 부분: 글쓰기 AI.
- AI 꺼진 기관: 한 줄 조립(위기도, 할 일 수, 달라진 생활영역).
- 시험: 사실 오류, 필수 맥락 누락, 반복 포함, 200자 초과.

### M8 목표 축 정리

- 하는 일: 목표마다 관련 카드를 회차순으로 모아 "처음"과 "지금"을 서술한다.
- 입력과 출력: 입력은 등록된 장기목표와 단기목표, 목표 연결이 달린 승인 카드, 목표 수정 이력(8월 검수). 출력은 목표별 진척 서술과 근거 회차, 회차별 방향 목록.
- 규칙: 스킬의 02 목표변화 그대로. "달성", "완료"는 원문에 있을 때만 쓴다. 퍼센트는 만들지 않는다. 근거 회차를 표시한다. 뚜렷한 근거가 없으면 진척 서술을 비운다. 축은 순서대로 고른다. 등록된 목표 → 없으면 첫 상담 기록의 지원욕구와 지원방향(참고 표시) → 그것도 없으면 M3 주제. 목표가 바뀐 이력이 있으면 어느 시점의 목표인지 표시한다.
- 하지 않는 것: 목표 문장 새로 쓰기. 진척도 계산.
- 비었을 때 문구: 축이 될 것이 없음 → "정리할 목표나 기록이 아직 없어요".
- AI가 필요한 부분: 서술 문장은 글쓰기 AI. 모으기는 규칙.
- AI 꺼진 기관: 등록 목표와 할 일 목록만.
- 시험: 근거 회차가 없는 문장 0건(구조). 사실 오류. 원문에 없는 판정어("달성") 사용 0건.

### M9 흐름 보기

- 하는 일: 처음부터 지금까지의 흐름을 여러 틀로 보여 준다. 회차별 한 줄, 회차 > 목표 > 주제 > 카드 나무 구조, 주제 타래, 핵심 지표, 자원 연계, 상황변화.
- 입력과 출력: 입력은 승인 카드와 꼬리표 전부. 출력은 경과 리포트의 회차별 요약, 01 상황변화, 핵심지표, 04 자원연계와 상담 기록 탭의 주제 타래.
- 규칙: 회차별 한 줄은 40~60자, 새로 나온 것 우선, 절차성 대화 제외, 한 주제로 도배하지 않는다. 핵심 지표는 회차마다 반복되는 숫자가 있을 때만 만들고, 급변 이유는 원문에 있을 때만 적고, 값이 다르게 적혀 있으면 각주로 남긴다. 자원 연계는 [기관N] 번호로 카드를 모아 회차순으로 잇는다. 표기가 다르면 그대로 남긴다. 주제 타래는 주제 하나의 카드를 상담일순으로 늘어놓는다.
- 하지 않는 것: 회차 접기와 묶기. 원문에 없는 이유 붙이기.
- 비었을 때 문구: 리포트 항목은 재료가 없으면 통째로 뺀다(스킬 원칙).
- AI가 필요한 부분: 회차별 한 줄과 상황변화의 처음/지금 문장만 글쓰기 AI. 나머지는 규칙.
- AI 꺼진 기관: 회차별 생활영역 목록, 등록 할 일, 위험 표시.
- 시험: 회차별 한 줄의 사실 오류. 핵심 지표 숫자가 원문과 같은지. 다른 기관을 하나로 잘못 묶는 비율.

### M10 제안

- 하는 일: 대조 결과를 질문 문장으로 다듬어 "오늘 물어볼 것"에 올린다. 약속한 일 카드에 [할 일로 등록]을 붙인다.
- 입력과 출력: 입력은 M5 불일치 쌍, M6의 열린 약속, 지난 회차의 확인할 것 카드. 출력은 세 묶음의 질문(D-A2). (지난 회차에 확인하기로 한 것) (아직 결과가 없는 약속) (서로 다르게 적힌 것).
- 규칙: 새 내용을 만들지 않는다. 질문마다 근거 카드가 달린다. 0개도 허용한다. 위 3개만 보이고 "N건 더"를 알린다. 위험 관련은 개수와 상관없이 맨 위. 같은 카드에서 나온 질문은 하나로 묶는다(A04). 읽기만 하면 된다. [숨기기]는 선택.
- 하지 않는 것: "정확히 2~3개" 강제(현행 지시문 규칙 폐기). 담당과 기한. 위험 배너, 남은 할 일과 겹치는 내용을 다시 제안.
- 비었을 때 문구: 재료 없음 → "지난 기록에서 물어볼 것을 찾지 못했어요". AI 꺼짐 → "AI가 꺼져 있어 제안하지 않아요".
- AI가 필요한 부분: 질문 문장 다듬기만 글쓰기 AI. 재료 고르기는 규칙.
- AI 꺼진 기관: 없음. 상태 문구만 보인다.
- 시험: 근거 카드 없는 질문 0건(구조). 현장 전문가가 "물어볼 만하다"고 본 비율(의미).

### M11 위험 신호

- 하는 일: 판단과 평가 카드와 당사자 발언 카드 중 위험 표시 유형 6가지에 해당하는 것을 제안한다.
- 입력과 출력: 입력은 그 회차의 카드(녹음 전사 포함). 출력은 위험 신호 제안(유형, 근거 카드).
- 규칙: 확정은 사람이 한다. 확정된 것만 위험 표시가 되어 배너에 오른다. 확정하지 않으면 제안으로만 남고 배너에 오르지 않는다. 확정을 요구하지 않는다. "반복"은 서로 다른 회차 2개 이상에 근거가 있을 때만 쓴다. 녹음이 없으면 제안하지 않는다(현행 지시문). 화면 안내 문구: "AI 위험 신호는 다음 영업일에 나오는 사후 점검용이에요. 상담 중 위기 대응을 대신하지 않아요."
- 하지 않는 것: 위험 등급 매기기. 지원 지속과 중단 판단.
- 비었을 때 문구: 녹음 없음 → "이 회차는 녹음이 없어 위험 신호를 살피지 않았어요". 확인했는데 없음 → "살펴봤고 위험 신호는 없어요".
- AI가 필요한 부분: 글쓰기 AI.
- AI 꺼진 기관: 수기 위험 표시.
- 시험: 심어 둔 위험 신호를 찾는 비율, 없는데 잡는 비율. 나이, 성별, 말투만 바꾼 쌍 문항(1차 점검 2-7). 유형 이름 "약속 불이행 반복"의 중립 이름은 지시문 버전 상승 때 정한다(A05).

## 6. 화면 항목과 모듈

## 7. 상담이 정석대로 안 갈 때

원칙은 하나다. 기록에 없는 것은 "안 일어난 것"이 아니라 "모르는 것"이다. AI는 기록만 본다. 그래서 이번 회차에 안 나왔다고 약속을 닫지도, 깨졌다고 하지도 않는다. 언급이 없으면 열어 두고, 닫는 것은 사람이 한다. 대신 "얼마나 오래 열려 있는지"는 숫자로 보여 준다. 오래됐다는 것은 정보이지 판단이 아니다.

| 상황 | AI가 하는 것 | 실무자에게 보이는 것 | 실무자가 하는 것 |
|---|---|---|---|
| 이번 회차에 아예 안 나옴(다른 급한 일) | 아무것도 안 함. 열린 채로 둠 | "3회차 약속, 2회 전, 아직 결과 없음" | 없음. 다음에 또 보임 |
| "했어요" | 결과 연결(했다) | "결과 기록이 있는 약속" 구역으로 내려가고 "5회차에 완료로 적혀 있어요" | 없음. 틀렸으면 다시 올림 |
| "아직요, 다음 주에" | 갱신 연결. 새 항목을 만들지 않음 | 항목 하나에 "3회차 약속, 5회차에 다시" | 없음 |
| "이제 필요 없어요" | 결과 연결(필요 없어졌다) | 아래 구역으로 내려가고 "5회차에 필요 없어졌다고 적혀 있어요" | 없음 |
| "못 했어요" | 결과 연결(못 했다). 열린 채로 둠 | "5회차에 못 했다고 적혀 있어요" | 없음. 원하면 [할 일로 등록] |
| 물어봤지만 메모에 안 적음 | AI는 모름. 열린 채로 둠 | 그대로 | 없음. 원하면 [해결됨] |
| 오늘은 일부러 안 꺼냄 | 열린 채로 둠 | 그대로 | 없음. 원하면 [숨기기] |
| 주제가 몇 회차 건너 다시 나옴(주거, 채무, 채무, 주거) | 뒤 회차 전부를 보므로 자연히 이어짐 | 6회차 주거 이야기가 2회차 것과 이어짐 | 없음 |
| 같은 약속이 여러 번 미뤄짐 | 미룬 회차를 이력으로만 붙임 | "3회차, 5회차, 7회차에 다시 약속" | 판단은 실무자 |
| 그 회차 기록이 짧거나 없음(전화, 예약 없이 내방) | "대조 범위 제한" 표시 | "4회차는 기록이 짧아 대조하지 못했어요" | 없음 |

덧붙이는 규칙 다섯 가지.

1. 낙인을 붙이지 않는다. 여러 번 미뤄진 약속은 미룬 회차만 나열하고 "반복 불이행" 같은 딱지는 달지 않는다. 왜 미뤄졌는지는 기록 밖의 일이다.
2. 목록이 길어지는 것은 자동으로 닫지 않고 보여 주는 방식으로 막는다. 오늘 물어볼 것에는 위 3개만 보이고 나머지는 "N건 더". 위험 관련은 항상 맨 위, 나머지는 오래된 순. 열린 항목이 10건을 넘으면 톺아보기 위에 "오래된 항목 N건 한 번에 정리하기"를 띄운다.
3. "지난 회차에도 안 나온 열린 항목 N건" 한 줄을 톺아보기에 둔다. 판단 없이 개수만 보여 줘도 실무자가 "이거 계속 못 물어보고 있네"를 알아챈다.
4. 기록을 나중에 입력하거나 고치면 짝 찾기를 다시 돌린다. 회차 순서는 입력한 날이 아니라 상담한 날 기준이다.
5. 서로 다른 말(불일치)도 같은 원칙이다. 뒤 회차에서 실무자가 확인해서 적을 때까지 남는다. 매 회차 바뀌는 숫자는 불일치가 아니라 변화로 핵심 지표에 넣는다.

## 8. 코드와 맞춰 볼 것, Q에게 확인할 것

코드로 확인할 것(레포를 내려받아 대조한다).

1. 승인 화면의 "대조 3종"이 M4와 겹치는지. 겹치면 M4는 그 기능을 넓히는 것으로 적는다.
2. ai-provider.ts 지시문이 만드는 카드의 종류와 칸이 4-1과 같은지. 1차 점검 2-2에서 스킬의 논리가 제품 코드에 없다고 확인했으므로, 무엇이 있고 무엇이 없는지 목록을 만든다.
3. briefing-cards.tsx의 빈 상태 문구를 3장 규칙 3의 세 상태로 바꿀 자리.
4. "정확히 2~3개" 규칙이 있는 자리(지시문, MAX_QUESTIONS, slice(0, 3)).

Q와 담당자에게 확인할 것.

5. 관계 가명([가족1], [채권자1])을 붙일지. 이번 범위는 번호만이다.
6. 번호 대응표를 어디에 두고 누가 볼 수 있는지(개인정보 담당).
7. 불일치 노출 범위(A01: 유지, 노출 축소, 중단).
8. 오늘 상담 기록의 9개 생활영역 칸을 유지할지. D-A3 뒤 이 칸의 역할은 AI 꺼진 기관의 회차 단위 주제와 통계뿐이다. 실무자 입력 부담과 견주어 결정한다.
9. "오래된 항목" 구역으로 내리는 기준(예: 5회차 이상 열림). 실무자에게 묻는다.
10. 한 번의 상담이 두 사례에 걸치는 실무가 있는지(8월 검수 Q 확인 3). 번호가 사례 단위라 여기에 걸린다.
11. 팀 스킬 두 개를 4-3에 맞춰 누가 갱신하는지.
