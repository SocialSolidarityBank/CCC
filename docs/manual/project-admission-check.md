# 확인하는 법: 사업의 저장 위치와 처리 경로 고르기

- 대상: 기관 관리자. 사업 등록 폼의 `확인하는 법` 링크가 여는 문서다
- 근거: ADR-0045(D87). 판단은 우리 기관이 하고 CCC는 정확히 알려 줄 뿐이다. 이 문서도 어느 쪽을 고르라고 말하지 않는다
- 매뉴얼 위치: 기존 매뉴얼 디렉터리가 없어(E10-4 매뉴얼 티켓 미착수) `docs/manual/`을 새로 만들었다. E10-4가 매뉴얼 자리를 정하면 그쪽으로 옮긴다

## 1. 무엇을 고르는가

사업을 등록할 때 두 가지를 고른다. 둘 다 기본 선택이 없고, 모르면 `나중에 정하기`로 두면 된다. `나중에 정하기`인 사업은 만들어지지만 당사자 등록과 녹음·AI 처리는 정하기 전까지 열리지 않는다.

| 구획 | 선택지 | 이런 경우 |
| --- | --- | --- |
| 데이터 저장 위치 | 기본형(기관 소유 Supabase 서울 프로젝트) | 발주처가 클라우드 종류나 보안 인증을 따로 요구하지 않는 경우 |
| | 네이버 클라우드 공공형 | 발주처가 국내 공공 클라우드나 CSAP 인증을 요구하는 경우. 아직 준비 중이라 지금은 고를 수 없다. 이 조건에 해당하면 도입 문의로 알려 주면 되고, 별도 계약과 설치가 필요하다 |
| | 나중에 정하기 | 아직 확인하지 못한 경우 |
| 녹음과 AI 정리 | 외부 업체 처리 허용 | 계약서에 외부 처리나 국외 이전을 막는 조항이 없는 경우 |
| | 기관 안에서만 처리 | 계약서가 외부 처리를 금지하는 경우 |
| | 나중에 정하기 | 아직 확인하지 못한 경우 |

고른 뒤 "위 선택은 우리 기관이 계약 조건을 확인하고 정한 것입니다"에 체크한다. 체크한 사람, 시각, 그때의 선택과 설명 문안 버전이 감사 기록에 남는다. 다시 체크해야 하는 때는 7절에 있다.

## 2. 외부로 무엇이 나가는가

`외부 업체 처리 허용`을 고르면 두 곳에 자료가 갈 수 있다. 둘은 나가는 것이 다르다.

| 업체 | 하는 일 | 나가는 것 | 지금 상태 |
| --- | --- | --- | --- |
| OpenAI(미국 회사) | 상담 내용을 AI가 정리 | 이름, 전화번호, 계좌번호를 지운 글만 | 기관 관리자만 키를 등록하고 최종 사용을 승인할 수 있다. 기관 기술 관리자는 연결 준비를 맡는다 |
| Azure 음성 인식(서울에 있는 마이크로소프트 서버) | 녹음을 글로 옮기기 | 녹음 파일을 지우기 전 그대로. 목소리가 밖으로 나간다 | 지금은 켤 수 없다. 켜려면 당사자에게 따로 허락을 받고, 관리자가 연결을 확인해야 한다 |

쉽게 말하면 이렇다. AI 정리는 글을 보내는데, 보내기 전에 사람을 알아볼 수 있는 말을 지운다. 음성 인식은 목소리 파일 자체를 보내서 지울 수가 없다. 그래서 음성 인식은 당사자 허락을 따로 받는다.

`기관 안에서만 처리`를 고르면 이 사업의 상담 자료는 기관 밖으로 나가지 않는다. 기관이 가진 PC, 노트북, 서버에서 처리하며 일정 이상의 성능이 필요하다. 최소 권장 사양의 숫자는 음성 인식 엔진 측정(STT-G1~G3)이 끝난 뒤 여기에 적는다. 지금은 기관 안에서 도는 음성 인식이 아직 없어서 녹음 없이 손으로 기록한다. 준비되면 설명이 바뀌고 다시 확인을 받는다.

이 문서의 "지금 상태"는 CCC 공통 상태다. 우리 기관 설치의 실제 값은 어드민 `AI·STT·연결` 탭에서 본다. 사업에서 `외부 허용`을 골라도 설치에서 꺼져 있으면 꺼진 것이다.

## 3. 용어 풀이

| 용어 | 뜻 |
| --- | --- |
| 발주처 | 이 사업을 우리 기관에 맡긴 정부, 지자체, 공공기관, 재단 등. 계약서나 과업지시서를 준 쪽 |
| CSAP | 클라우드 보안인증. 공공기관이 쓰는 클라우드 서비스에 요구되는 국내 인증 제도. 계약서에 "CSAP 인증을 받은 클라우드", "공공 클라우드"라고 적혀 있으면 이것이다 |
| 처리위탁 | 우리 기관이 가진 개인정보를 다른 업체가 대신 처리하게 맡기는 것. CCC에서 OpenAI, Azure에 자료를 보내는 것이 여기에 해당한다 |
| 재위탁 | 위탁받은 업체가 다시 다른 업체에 맡기는 것. 발주처 입장에서는 우리 기관이 수탁자이고 OpenAI, Azure가 재수탁자가 된다 |
| 국외 이전 | 개인정보를 대한민국 밖으로 보내는 것. OpenAI는 미국이라 여기에 해당하고, Azure 서울 리전은 국내다 |
| 가림 처리(마스킹) | 이름, 연락처, 계좌, 주소, 제3자 이름 등을 지우거나 가명으로 바꾸는 것. CCC는 AI 정리에 보내기 전 두 번 가린다 |

## 4. 계약서에서 볼 조항 이름

문서 종류에 따라 이름이 다르다. 계약서 본문, 과업지시서(과업내용서), 보안 서약서(보안 관리 계획, 개인정보 보호 준수 서약)를 같이 본다.

| 찾는 것 | 흔한 조항 이름 |
| --- | --- |
| 클라우드 종류나 보안 인증 요구 | 정보시스템 요건, 보안 요구사항, 클라우드 이용, 데이터 보관 위치, 시스템 구축 환경 |
| 외부 업체 처리, 재위탁 제한 | 개인정보 처리위탁, 재위탁 금지(승인), 제3자 제공 제한, 비밀유지 |
| 국외 이전 제한 | 개인정보 국외 이전, 역외 저장 금지, 데이터 국내 보관 |
| 발주처 지정 업무 시스템 | 전산 시스템 사용, 지정 시스템 입력 의무, 사업관리 시스템 |

조항이 없으면 없는 것이다. 없다는 것을 확인한 뒤 고르면 된다. 찾지 못했거나 읽어도 판단이 서지 않으면 `나중에 정하기`로 두고 5절의 담당에게 묻는다.

## 5. 물어볼 부서

| 물음 | 담당 |
| --- | --- |
| 이 조항이 우리 사업에 적용되는가, 추가 요구가 있는가 | 발주처 사업 담당(계약서에 적힌 담당 부서) |
| 처리위탁, 재위탁, 국외 이전이 우리 기관 규정에 맞는가 | 우리 기관 개인정보 보호 담당(개인정보 보호책임자) |
| 계약서 원본과 부속 문서 전체 | 우리 기관 계약·회계 담당 |

## 6. AI에게 물어보기

계약서를 빨리 훑고 싶을 때 쓰는 복붙 프롬프트다. 결과는 조항의 있고 없음을 정리한 표이고, 어느 쪽을 고를지는 사람이 정한다. 붙여 넣는 곳은 우리 기관이 쓰는 AI 도구이고 CCC와 무관하다.

**붙여 넣기 전에 계약서에 있는 사람 이름과 연락처는 지운다.**

> 아래 문서를 읽고 다음 세 가지를 찾아 표로 정리해 주세요. **어느 쪽을 고를지 판단하지 말고**, 해당 조항이 있으면 조항 번호와 원문을, 없으면 "찾지 못함"이라고만 적어 주세요.
> 1. 발주처가 특정 클라우드, 국내 공공 클라우드, 또는 CSAP 같은 보안 인증을 요구하는 조항
> 2. 개인정보를 외부 업체에 맡기는 것(처리위탁, 재위탁), 국외로 보내는 것을 제한하거나 금지하는 조항
> 3. 발주처가 정해 준 업무 시스템을 써야 한다는 조항
>
> [여기에 계약서, 과업지시서, 보안 서약서 내용을 붙여 넣으세요]

표가 나오면 4절의 조항 이름과 맞춰 보고, 최종 확인은 5절의 담당에게 한다.

## 7. 언제 다시 확인하는가

한 번 확인한 사업도 아래 세 경우에는 다시 확인해야 한다. 다시 확인하기 전까지 그 사업은 새 당사자 등록, 녹음, AI 정리가 잠긴다. 이미 있는 기록은 그대로 볼 수 있다.

| 무엇이 바뀌었나 | 왜 다시 보나 | 화면에 뜨는 말 |
| --- | --- | --- |
| 이 사업의 선택을 바꿨다 | 확인한 내용과 지금 고른 내용이 다르다 | "고른 내용이 바뀌었습니다. 바뀐 내용을 다시 읽고 확인해 주세요." |
| 기관의 음성 인식이나 AI 설정이 바뀌었다(예: 기관 관리자가 Azure 음성 인식 사용을 승인했다) | 설정 하나가 바뀌면 이 기관의 모든 사업에서 자료가 밖으로 나가는 방식이 함께 바뀐다. 확인할 때 본 "무엇이 나가는가"가 더 이상 맞지 않는다 | "기관의 음성 인식이나 AI 설정이 바뀌어서, 이 사업의 상담 자료가 밖으로 나가는 방식도 바뀌었습니다. 무엇이 나가는지 다시 읽고 확인해 주세요." |
| 이 설명 글이 바뀌었다 | 확인할 때 읽은 글과 지금 글이 다르다 | "설명 글이 바뀌었습니다. 바뀐 설명을 다시 읽고 확인해 주세요." |

두 번째 경우는 관리자 한 사람의 설정 한 번이 사업 여러 개를 잠근다. 그래서 `AI·STT·연결` 탭은 저장하기 전에 "이 설정을 저장하면 N개 사업의 자료가 밖으로 나가는 방식이 바뀝니다"를 먼저 보여 준다.
