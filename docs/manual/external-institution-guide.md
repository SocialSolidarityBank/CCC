# 외부 기관 안내: 이 프로그램을 가져다 쓰는 법

- 대상: 이 프로그램을 자기 기관에 설치해 쓰려는 외부 기관
- 소스: `https://github.com/SocialSolidarityBank/CCC` (Apache License 2.0, `LICENSE`)
- 이 문서는 2026-09-17 첫 출고 기준이다. 지원 범위는 4절과 5절이 정본이다

## 1. 이 프로그램이 무엇인가

금전 지원 사업 당사자 상담을 인테이크부터 종결까지 기록하는 웹 프로그램이다. 상담 전에 지난 기록을 한 화면으로 훑게 해 주는 것이 목적이고, AI 정리는 보조 수단이다. 기관이 직접 소유한 Supabase 프로젝트에 데이터를 두고, 배포 기관은 소스와 설치 절차만 제공한다.

## 2. 무엇이 필요한가

| 필요한 것 | 용도 | 없으면 |
| --- | --- | --- |
| 기관 소유 Supabase 서울 리전 프로젝트 | 상담 기록, 금고, 동의, 감사 기록이 저장되는 데이터베이스와 인증 | 없으면 설치 자체가 안 된다. 다른 리전이나 이미 데이터가 있는 프로젝트는 설치 점검(`plan`)이 거부한다 |
| 처리용 기관 PC 한 대 | AI 정리와 녹취 전사를 켤 때만 필요한 처리 장비. 외부로 나가는 글을 한 번 더 가리는 자리다 | AI와 전사를 켜지 않으면 필요 없다. 수기 기록만으로 업무 한 바퀴를 돌 수 있다 |
| 운영자 본인 계정의 외부 소프트웨어 키 | OpenAI 키는 AI 정리를, Azure 키는 자동 전사를 켤 때 필요하다. 기관이 직접 발급하고 직접 요금을 낸다 | 키가 없으면 해당 기능이 꺼진 채로 둔다. 설치 기본값은 둘 다 꺼짐이다 |

## 3. 어떻게 시작하는가

설치는 이 레포에 이미 있는 명령을 순서대로 실행하는 절차다. 새 절차를 만들지 않고 아래 두 파일이 정본이다.

- `apps/community-cloud/RUN.md`: 컨테이너 빌드, 필수 연결값, 설치 명령의 정본
- `docs/specs/S12-install-release.md`: 설치·갱신·복구 계약의 정본

순서는 이렇다.

1. 레포를 받고 `pnpm --filter @ccc/community-cloud build`로 실행 묶음을 만든다.
2. `RUN.md`의 도커 빌드 명령으로 컨테이너 이미지를 만든다.
3. `pnpm supabase:bootstrap -- plan --target hosted --project-ref <프로젝트-식별자>`로 기관 프로젝트가 설치 가능한 상태인지 읽기 전용으로 점검한다. 이 단계는 아무것도 바꾸지 않는다.
4. 점검이 통과하면 `apply`로 설치한다. 서명된 설치 정보(`--manifest-url`)가 필요하다.
5. `create-institution`으로 기관을 만들고, `link-first-admin`으로 첫 관리자 계정을 연결한다. 관리자 계정은 Supabase Auth에서 먼저 만든다.
6. 첫 로그인이 기관 이름과 첫 사업을 정하는 초기 설정이다.

이 절차는 명령행과 서명 파일을 다룬다. 기술 담당이 없는 기관에서는 AI 에이전트와 함께 진행하는 것을 전제로 한다. 각 명령이 요구하는 값과 거부 코드는 `RUN.md`와 `docs/ops.md`의 사전 점검 표에 있다.

## 4. 지원하는 범위

첫 출고는 기관 소유 클라우드(Community Cloud) 한 모드이며, 업무 한 바퀴를 다룬다.

- 역할: 기관 관리자와 실무자. 관리자는 기관 전체를 읽고 설정을 관리하며, 실무자는 자기가 담당한 당사자의 기록을 쓰고 읽는다. 실무자 계정은 관리자가 Supabase Auth에서 직접 만든다.
- 당사자 등록과 인테이크: 실무자가 당사자를 등록하고 고정 양식의 인테이크 기록을 작성한다. 동의 항목은 등록 시점에 함께 기록한다.
- 상담 기록: 회차별 상담 기록을 수기로 작성하고, 일정과 목표를 관리한다.
- 회차 요약과 실무자 승인: AI가 정리한 회차 요약은 실무자가 검토하고 승인해야 공식 기록이 된다. 승인 전 초안은 브리핑과 통계에 나가지 않는다.
- 녹음 파일 업로드: 회차 상세 화면에서 녹음 파일을 올릴 수 있다. 설치의 전사 설정이 켜져 있을 때만 보이며, 처리가 끝난 원음은 서버가 즉시 삭제하고 업로드 뒤 7일을 넘기지 않는다.
- CSV 반출: 케이스 단위로 기록을 CSV로 보낸다.

## 5. 지원하지 않는 범위

아래 항목은 삭제된 것이 아니라 이번 출고 범위 밖이다. 없는 것을 있는 것처럼 안내하지 않는다.

| 항목 | 지금 상태 |
| --- | --- |
| 당사자 로그인과 요청 링크 | 당사자가 링크로 직접 들어와 쓰는 공개 화면은 꺼져 있다. 등록은 실무자가 대행한다 |
| 로컬 설치 모드 둘(Local Single, Local Office) | 계약에는 있지만 이번 출고는 기관 소유 클라우드 한 모드만 제공한다 |
| 기관 안에서 도는 전사 엔진(로컬 STT) | 코드 경로는 있으나 이번 출고에서 선택지로 열지 않는다. 전사를 쓰면 Azure 경로다 |
| 감정 분석 | 보류다. 스키마와 코드는 남아 있으나 계산을 멈춰 두었다 |
| HWPX·DOCX 반출 | 없다. 반출은 CSV뿐이다 |
| 사업 도입 확인의 서버 거부 잠금 | 사업 등록 시 저장 위치와 처리 경로를 고르는 확인은 결정됐으나, 미확인 사업을 서버가 거부하는 잠금은 아직 구현되지 않았다. 화면 안내가 차단을 대신하지 않는다 |
