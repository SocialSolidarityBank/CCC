## 1. 서비스 개요 (검토 배경)

비영리 기관의 금전 지원 사업 당사자 상담을 기록·관리하는 웹 서비스다. 상담을 녹음해 텍스트로 변환하고, AI가 상담 기록을 요약·정리해 다음 상담 전에 실무자에게 브리핑한다. 개인정보(성명·연락처 등)는 암호화 금고에 분리 저장하고, AI에 보낼 때는 실명을 가명 ID로 치환하고 추가 마스킹을 거친다(2단계 보호). 현재는 사회연대은행 한 기관이 사용하며, 향후 여러 기관이 각자 쓰는 서비스로 확장 예정이다.

## 2. 동의 처리의 현재 구현 (사실 관계)

문안 검토 시 전제가 되는, 시스템이 실제로 하는 일이다.

- **동의 3종을 항목별로 구분해 받는다**: ① 개인정보 수집·이용 ② 녹음·음성 분석 ③ 텍스트 AI 정리. ②·③은 선택이며, 거부해도 등록·상담에 불이익이 없다. ①도 미동의 상태로 등록·상담 진행이 가능하다(게이트 아님).
- **동의는 오프라인(서면·구두)으로 받고**, 시스템에는 항목별 동의 여부·일시·기록자만 기록한다. 입력은 실무자가 대행한다(당사자 직접 작성·전자서명은 이번 검토 후 도입 예정).
- **받는 자리와 고치는 자리가 분리**돼 있다: 당사자 등록 시 받고, 당사자 정보 페이지에서 수정·철회하며, 인테이크(초기 상담) 화면은 읽기만 한다.
- **철회 이력은 지워지지 않는다**: 철회하면 현재 상태는 미동의로 바뀌지만, 변경 이력은 추가 기록(append-only)으로 남고 기존 이력을 고치는 경로는 DB가 차단한다. 모든 변경은 감사 기록으로 남는다.
- **동의 단위는 "참여 사업"**이다: 같은 당사자가 두 번째 사업에 참여하면 동의 3종을 처음부터 다시 받는다(앞 사업의 동의를 물려주지 않음).
- **녹음 원본은 30일 뒤 자동 삭제**되고, 텍스트 AI 처리 전에 성명·연락처를 가명·마스킹 처리한 뒤 외부 AI 서비스(Anthropic Claude API, 해외 사업자)로 보낸다. 마스킹은 자동화 특성상 완벽하지 않을 수 있어 잔여 위험을 문안에 고지했다.
- **보유 기간**: 상담 종결 후 기본 1년(기관 규정에 따름)이 지나면 즉시 파기가 아니라 접근이 제한된 보관(아카이브) 상태로 전환하고, 파기는 별도 판단으로 진행한다.

## 3. 검토 질문 7건

1. **문안 전반** — `consent-draft-v0.md` 6개 절이 개인정보보호법 제15조 제2항(목적·항목·기간·거부 권리 고지)과 제22조(항목별 구분 동의) 요건을 충족하는가? 표현·구성에서 보완할 곳은?
2. **열람 범위 고지(4절)** — "같은 기관의 다른 실무자에게는 참여 중인 사업 목록과 담당 실무자 이름이 표시된다"는 고지가 충분한가, 아니면 별도 동의가 필요한 제3자 제공에 해당하는가? (같은 기관 내부 공유이고, 상담 내용·개인정보는 담당자로 한정된다)
3. **AI 위탁·국외 이전(5절)** — 가명·마스킹 처리 후 해외 AI 사업자(Anthropic)에 보내는 것이 처리위탁·국외 이전 중 무엇에 해당하며, 현재의 고지("외부 AI 서비스에 위탁 처리" + 잔여 위험)로 충분한가? 국외 이전 별도 고지·동의가 필요한가?
4. **보유·아카이브(3절)** — 보유 기간 경과 후 즉시 파기하지 않고 접근 제한 보관(아카이브)으로 전환하는 방식이 제21조 파기 원칙과 정합하는가? 아카이브 보존 상한과 최종 파기 시점을 어떻게 정해야 하는가? 보유 기간 "기본 1년"의 근거로 내부 규정 외에 참조할 법정 기준이 있는가?
5. **사업 단위 재동의** — 같은 당사자의 두 번째 참여 사업에서 동의 3종을 처음부터 다시 받는 현재 구조가 맞는가, 아니면 기관 단위 1회 동의로 갈음할 수 있는가?
6. **전자서명·당사자 직접 작성** — 당사자가 초대 링크로 직접 가입하며 화면에서 체크하는 방식으로 동의를 받으려면 어떤 요건(본인 확인, 서명 방식, 기록 보존)을 갖춰야 하는가?
7. **대행 입력의 증빙력** — 서면·구두로 받은 동의를 실무자가 시스템에 체크로 기록하는 현재 방식이 동의 증빙으로 충분한가? 종이 원본 보관 등 병행해야 할 조치가 있는가?

## 4. 참고 화면 (동의가 나타나는 자리)

- **당사자 등록 화면** (`/participants/new`) — 동의 3종 체크 + "자세히 읽어보기" 아코디언(문안 6절 전문 표시)
- **당사자 정보 페이지** (`/participants/:id`) — 참여 사업 카드마다 동의 3종 수정·철회 UI + 마지막 기록 시각
- **인테이크(초기 상담) 화면** — 동의 상태 읽기 전용 표시, 미기록 시 등록 화면 링크만
- **자기 가입 폼** (`/join/participant/:token`, 배포 전 프로토타입 — PR #5) — 등록 화면과 같은 3종 체크·같은 문안

화면 캡처가 필요하면 요청 시 첨부한다(가상 시드 데이터로 캡처 — 실제 개인정보 없음).
