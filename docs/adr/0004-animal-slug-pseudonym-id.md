# 가명 ID를 동물 슬러그 형식으로 교체

> **2026-07-18 일부 대체(ADR-0009, D31)**: 화면 한글 표시("제비 003")와 A017 마이그레이션 필요성은 폐기 — 가명 ID는 기계 식별자·경계 통과 토큰으로 재정의됐다. 슬러그 형식과 의미 정보 금지 원칙은 유지.

2026-07-15 확정. 가명 ID를 `A017` 형식에서 **희망 상징 동물 영문 슬러그 + 동물별 순차번호**(예: `swallow-003`)로 교체한다. 화면에는 한글로 표시한다(예: "제비 003"). 브랜딩과 기억성 때문 — 상담사가 "A017님"보다 "제비님 케이스"로 기억하기 쉽고, 상담 준비 화면 HERO에 크게 두는 새 레이아웃에서 제품 정체성이 된다.

**가입일자·사업 유형 등 의미 정보는 넣지 않는다.** 검토 과정에서 "동물이름 + 가입일자 + 순차번호" 안이 나왔으나, 날짜가 ID에 박히면 준식별자가 되어(작은 조직에서 "7월 초 등록자 = 아무개"로 역추적) 가명화 취지를 깨므로 기각했다.

## Consequences

- DB·URL·검증 정규식(`/^A[0-9]{3,}$/`)이 여러 파일에 박혀 있어 기존 파일럿 데이터 마이그레이션과 web/api 검증 수정이 필요하다.
- URL·DB는 영문 슬러그, 화면은 한글 — 동물별 영↔한 매핑 테이블이 단일 출처로 필요하다.
- 동물 이름 풀은 희망·회복을 상징하는 종으로 큐레이션한다(스펙에서 확정).
