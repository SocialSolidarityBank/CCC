# ADR-0049: 릴레이어 카드 계약과 AI 모듈 기준

- 상태: Accepted (2026-09-13 Q가 베타 구현 착수와 총괄의 세 머신 배치를 승인. 개인정보 보관 정책, 실데이터 사용, 외부 AI 활성화, 보호 브랜치 머지, 운영 배포 승인이 아님)
- 결정일: 2026-09-12 그릴링, 2026-09-13 구현 착수
- 결정 번호: D90
- 관련: ADR-0018, ADR-0032, ADR-0036, ADR-0037, ADR-0046, ADR-0047, S6, S13, [적용 계획](../superpowers/plans/2026-09-12-relayer-domain-ai-replan.md)
- 부분 대체: ADR-0018의 브리핑 상시 편집과 무구분 빈 상태 표시, ADR-0037의 "정확히 2~3개" 질문 계약, 고정 category 6개를 전제한 팀 스킬 서술
- 유지: 수기 즉시 공식 기록(R2), 마스킹 스냅샷 게이트(R3), AI 판단 금지(R5), 대조 3종의 누락·미논의 목표 축, 승인 1회, 원본 불변, 위험 신호 6종의 코드 식별자

## 배경

2026-09-12 설계 문서 묶음은 카드 4종, 생활영역 9개, 자유 주제, 상태 문구, 약속 추적과 AI 모듈 M1~M11을 요구한다. `origin/main@ad218e8e` 실측에서 AI 출력은 `claimKey/section(3)/text/evidence` 구조였고, 생활영역은 서버 6키와 인테이크 9선택지로 갈려 있었으며, 질문 2~3개 강제와 상담 기억의 AI 입력 사용이 남아 있었다. 라벨 교체만으로는 요구가 적용되지 않는다.

## 결정

1. **분류 축은 서로 독립이다.** 카드 종류 4(사실, 확인할 것, 약속한 일, 판단과 평가), 사람이 고르는 생활영역 9, AI가 찾는 사례 내 자유 주제, 목표 위계, 위험 신호 6종, 동의 6영역을 섞지 않는다. 요약 3구획을 카드 종류로 오인하지 않는다.
2. **표시명과 저장 식별자는 분리한다.** 화면 이름과 용어는 2026-09-12 결정대로 바꾸되 라우트, DB 키, 코드 식별자, 과거 ADR 문장은 유지하고 대체 관계를 기록한다.
3. **사람 / AI / 규칙의 경계.** 사람은 수기 기록, 합의 목표, 위기도, 약속 결과, 위험 신호 확정, AI 초안 승인을 한다. AI는 근거 있는 카드·비교·주제·문장을 제안한다. 규칙 코드는 권한, 동의, 마스킹 증거, 정렬, 개수, 상태와 버전을 판정한다. 배열이 비었다는 이유로 검사 성공을 주장하지 않는다.
4. **공통 근거 계약.** 카드에는 사례, 회차, 상담일, 출처 종류와 원문 revision/hash, 근거 인용/offset, 카드 종류, 화자, 명시된 행위자/기한, 주제, 목표 연결, 인물/기관 번호, 승인 출처가 있어야 한다. 결과와 갱신 연결은 원본 카드를 보존한다. 처리 상태는 검사 범위, revision, 성공/미실행/대기/차단/부분 처리를 구분한다.
5. **불일치 검출 기준.** ADR-0018 보완대로 맥락이 확실하고 서로 양립할 수 없는 기록만 검출한다. 단순 값 차이, 정상 변화, 표현 차이는 제외하고, 누락 확인과 내용 상충은 구분한다.
6. **상담 기억 그림자.** 화면 숨김이 아니라 제품 AI 요청의 기억 입력 차단이다. 생성·저장·정정·파기 계약은 유지한다.
7. **품질 판정.** 구조 검사와 의미 품질을 분리한다. 새 모듈의 정답표는 구현자와 독립적으로 만들고, 기존 S13/S6 수치를 새 모듈에 자동 복사하지 않는다.
8. **실행 순서.** 용어와 소비 계약 → AI 없이 성립하는 입력과 상태 → 처리 상태와 그림자 격리 → 가림 → 카드/주제 → 대조/약속 추적 → 요약·목표·질문·위험 신호 → 화면·리포트 → 독립 검증 → 출고. 등록 할 일 목록을 개명해 약속 추적 완료로 보고하지 않는다.

## 결과

- 첫 구현 묶음은 기존 계약 위에서 시작한다: 클라이언트 라벨과 첫 상담 기록 진입, 그리고 명확한 상충 기준과 기억 입력 격리. 새 카드 저장 정본, 생활영역 데이터 이전, 번호 가명 대응표는 G1/G5/G7 결정 뒤에 적용한다.
- 미결 관문(G1, G3~G8)은 계획 §6이 갖는다. 관문이 열리기 전 해당 저장 계약을 발행하지 않는다.
- 분산 실행: MacBook 총괄과 frontend, Mac mini 코어, Windows 실행 검증. 한 워크트리에는 작성자가 하나이며 검증은 작성 중단 뒤 한 번에 수행한다.
