# 플랫폼은 웹 우선, 외부 배포 시 PWA 추가

2026-07-15 확정. 장기적으로 외부(다른 비영리 조직) 배포를 계획하지만, 1차 완성은 7월말 집중 개발 기한에 맞춰야 한다. 이미 배포까지 끝난 Next.js + Cloudflare Pages 반응형 웹앱을 유지하고, 외부 배포 시점에 PWA(홈 화면 설치·푸시)를 얹는다. 네이티브 앱은 만들지 않는다 — Cloudflare Access 인증이 브라우저 기반이라 궁합이 나쁘고, 내부 도구 규모(50명 이하) 대비 스토어 배포·PII 기기 캐싱 보안 검토 비용이 크기 때문. 실사용 피드백에서 네이티브가 필요하다고 증명될 때만 재검토한다.

모바일 대응은 반응형으로 해결한다(상담 준비 화면: 웹 2열 / 모바일 1열 아코디언).
