# 디자인 리프레시 v1 — 그라데이션 위계·모션 3종·역할표·사이드바 고정

2026-08-02 그릴링(D58)으로 확정한 일곱 결정을 기록한다. 색값은 **한 개도 바꾸지 않는다** — pen '색 토큰' 페이지가 SSOT 라는 지위(D34·ADR-0012)는 그대로다. 바뀌는 것은 **기존 색·형태를 어디에 어떻게 쓰는가**의 규칙이다.

문제의식(Q, 2026-08-02): "우리 디자인의 핵심은 컬러 그라데이션인데 정지 화면에만 있고, 글자색이 사실상 한 가지뿐이며, 클릭 가능한 것과 아닌 것이 형태로 구분되지 않는다."

## 결정

### 1. 그라데이션 허용 범위 — 형태(알약 vs 카드)로 가른다

**알약(pill) 형태는 그라데이션이 기본이다**: 중요(프라이머리) = `--gradient-action` 채움(현행 유지), 일반(세컨더리) = **`--gradient-brand` 1px 아웃라인**(배경 2겹 방식, §3-3)으로 바꾼다. **카드(radius 12)는 현행 유지** — 회색 `--line` 1px 이 기본이고 선택·활성일 때만 그라데이션 테두리다.

2026-07-26 결정("모든 카드에 두르면 촌스럽고 리스크 배너가 묻힌다")과의 공존 장치가 **형태 구분**이다: 알약과 카드는 radius 부터 다르므로(9999 vs 12) 같은 그라데이션이라도 신호가 섞이지 않는다.

**리스크 배너 테두리는 `--gradient-brand` 1.5px → `--risk` 단색 1.5px 로 바꾼다.** 세컨더리 버튼이 브랜드 그라데이션을 두르면 배너의 유일성이 테두리에서 사라지므로, 배너는 위험 버튼과 같은 어휘(빨강 1.5px 테두리)로 옮겨 "빨강 테두리 = 위험"을 한 축으로 모은다. 새 그라데이션은 만들지 않는다 — §3-3 "5개만" 계약은 유지된다. 2026-07-26 변경 ①("`--gradient-risk` 폐기, 배너도 브랜드 그라데이션")의 재개정이다.

D55(ADR-0025)의 "일반과 강조의 구분은 테두리가 아니라 면과 깊이"는 **부분 개정**된다 — 구분의 1차 축은 여전히 면(채움 유무)이지만, 세컨더리 테두리가 `--line-action` 잉크 50% 에서 브랜드 그라데이션으로 바뀐다.

### 2. 모션 3종 — 흐름·눌림·떠오름, 이 셋 밖의 모션은 위반

| 이름 | 트리거 | 동작 | 대상 |
| --- | --- | --- | --- |
| **흐름** | 호버 | 그라데이션 위치가 좌→우로 흐르듯 이동 (`background-size` 200% + `background-position` 이동, 호버 동안만) | 그라데이션을 가진 요소(프라이머리 채움·세컨더리 아웃라인·선택 카드 테두리) |
| **눌림** | 클릭 | `translateY(1px)` (§5 현행 그대로 — 새로 만들지 않고 승격) | 모든 버튼·클릭 행 |
| **떠오름** | 스크롤 진입 | `opacity 0→1` + `translateY(8px→0)`, **페이지당 첫 진입 1회만** | 카드·섹션 |

공통 계약: 지속 시간 2단(빠름 120ms = 눌림·워시, 기본 200ms = 흐름 진입·떠오름)과 이징 1종을 토큰으로 신설(`--motion-fast`·`--motion-base`·`--ease-standard`). 그라데이션이 없는 요소의 호버는 현행 잉크 6% 워시 유지 — 워시는 상태 표시지 모션이 아니므로 3종에 세지 않는다. `prefers-reduced-motion` 계약(tokens.css)은 그대로 적용된다.

§6 v1 의 "스크롤 트리거 모션 금지"는 이 결정으로 **개정**된다 — 금지의 원래 목적(업무 도구에서 훑기 방해 방지)은 "첫 진입 1회·8px·200ms" 상한이 승계한다. 장식용 무한 반복 금지는 유지하되, **흐름(호버 동안 반복)만 명시 예외**다 — 사용자가 손을 올린 동안만 도는 것은 장식이 아니라 반응이다.

### 3. 타이포 — 크기 계단은 유지, 역할표를 계약으로 승격

크기 5단(14·16·18·24·28)과 하한 14px, 계단식 토큰 이름은 **그대로**다(D55 유지 — 12px 캡션 신설안은 접근성 하한과 §9 예외 확대를 이유로 기각). 확정한 것은 **역할 대응**이다: 캡션·라벨·메타 = 14 / 본문 = 16 / 카드·섹션 제목 = 18 / 헤딩 = 24(좁은 화면)·28. §2 의 역할표(단계 표)가 이미 이 대응을 갖고 있으므로 문서상 신설이 아니라 **"이 표 밖의 크기-역할 조합은 위반"이라는 지위 승격**이다.

### 4. 글자색 다양화 — 배지 중심, 의미는 계열에 고정

본문 글자색은 `--ink`(기본)·`--sub`(보조) 둘을 유지하고, **강조는 색이 아니라 굵기 700** 이다(deep 색의 본문 확산은 라이트 대비 2.0~2.5 라 기각). 데이터 나열의 구분은 **계열 배지·칩**(tint 배경, D47 계열 칩 3종)이 맡고, 의미를 고정한다:

| 계열 | 의미 축 |
| --- | --- |
| 블루 | 일정·시간·유형·정보 |
| 민트 | 진행·상태·담당(사람·소속) |
| 라벤더 | AI 산출·승인 대기 |
| 리스크 핑크 | 확인된 경고 **전용** (D9 유지) |

D47 칩 3종의 축(유형=블루, 담당=민트, AI=라벤더)과 정합하며, GAS 긍정·감정을 색으로 판정하지 않는 원칙(D6·R4, `--success` 폐기)은 그대로다.

### 5. 사이드바 — 280px·화면 고정·하단 묶음 상시 노출

- 폭 **240 → 280**(`--sidebar-width`). 1440 캔버스에서 본문 영역 1160, 컨테이너 1120 유지(잔여 40). D37/ADR-0015 의 §4-1 표와 §7 락 8 의 숫자만 개정하고, 나머지 레이아웃 수식(1120·40·브레이크포인트 767)은 불변.
- 사이드바는 **뷰포트에 고정**된다(`position:sticky; top:0; height:100dvh`) — 본문이 스크롤해도 제자리. 메뉴가 넘치면 사이드바 **안에서만** 스크롤.
- 하단 묶음(설정·테마 전환·로그아웃)은 사이드바 발치에 **상시 노출** — D50·D56 의 발치 배치를 "스크롤과 무관하게 항상 보인다"로 강화.

### 6. 클릭 가능성은 형태로 — 단독 클릭 요소는 전부 알약

홀로 서 있는 클릭 요소(화면 하단 이동 링크·카드 안 처리 버튼·필터 등)는 전부 알약 버튼이다 — 중요하면 채움, 일반이면 아웃라인(결정 1). **문장·표 안 인라인 참조 링크만** 밑줄 텍스트로 남는다. 예외 재확인: 사업 전환기·HERO 상태 태그는 알약이 아니라 radius 6 컨트롤(§4-5·§3-1 현행 유지 — 행동이 아니라 값이다).

### 7. 아이콘 — 사이드바 SVG 시스템을 공용으로 승격, 문자 글리프 금지

사이드바의 16px·stroke 1.5·`currentColor` 라인 SVG 시스템을 공용 아이콘 부품으로 승격하고, 화면 32곳의 문자 글리프(⚠·✓·●·○·▸ 등)를 전부 치환한다. 문자 글리프는 OS·폰트마다 렌더가 다르고 다크 모드에서 색 제어가 안 된다. 크기는 §3-4 현행(내비·인라인 16, 헤더 18) 유지.

## 하지 않은 것

- **색값 변경 0** — pen SSOT 불변. 새 색조·새 그라데이션 없음.
- **z-index 재설계 없음** — 4층 계약(0·10·30·100)과 사용처 5곳 전부 토큰을 쓰고 있어 정리할 대상이 없었다. 화면에서 겹침이 보이면 그것은 층 문제가 아니라 개별 버그로 잡는다.
- **12px 캡션 없음** — 하한 14 유지(결정 3).
