# ADR-0046: 상담 기억은 승인 없는 보조 맥락으로 자동 유지한다

상태: 사용자 확정, 2026-09-08. 백그라운드 생성·갱신·저장과 내부 활용, 안전 경계 및 기관 설정의 구현 기준으로 유지한다.

> **2026-09-08 Q 후속 범위 결정:** 전 버전에서 제안한 현재 맥락 요약 전용 UI, 독립 기억 상세 화면과 링크, 기억의 15초 페이지 직접 출력은 이번 단계에서 철회한다. 이 결정은 출력 UI 범위만 대체하며 기억 생성·갱신·저장, 내부 요약 데이터 모델, 정정 규칙, 파이프라인 활용, 접근·개인정보 보호, 기관 단위 켜기/끄기 설정을 삭제하지 않는다. 기억은 이 단계에서 내부 지원 맥락을 생성하고 갱신해 저장하는 데서 멈춘다. 향후 15초 페이지의 '오늘 만나기 전 꼭 기억할 것'과 '상담 내용 회차별 정리', '상담 기록 확인하기'에 보조 문장을 더할 수 있으나, 출력 위치와 문구를 포함한 설계는 별도 결정으로 남긴다.

상담 기억은 한 사업의 케이스에 속하는 내부 지원 맥락이다. 기록에 명시된 사실과 여러 회차를 종합한 기억 관찰을 개별 항목으로 유지하고, 그 항목에서 현재 맥락 요약을 만든다. 실무자 개인 선호나 다른 사업의 상담 기억은 합치지 않는다. 공식 기록을 대신하거나 현재 회차의 발언 근거로 가장하지 않는다.

사용자는 기억의 개별 승인과 일상적인 수동 관리를 명시적으로 기각했다. 기존 공식 기록을 소급 처리하고 이후 기록·목표·액션 변경에 따라 백그라운드에서 자동 갱신한다. 사람이 필요할 때 기억을 직접 정정할 수 있는 코어·HTTP 계약은 유지한다. 정정은 같은 과거 근거로 되돌아가지 않으며 이후 명확한 새 근거에 따른 갱신은 허용한다. 정정 UI와 독립 상세 링크는 이번 단계의 범위가 아니다.

## 공식 기록과의 구분

R2의 상담 기록 승인 원칙은 유지한다. 미승인 AI 상담 초안을 기억 재료로 사용하거나 기억을 원본 상담 기록으로 승격하지 않는다. 상담 기억과 현재 맥락 요약은 별도의 자동 생성 보조 표현으로서 공식 기록과 구분해 저장한다. 기존 회차별 요약·대조·플래그 확정 절차를 바꾸지 않는다.

기억은 회차별 AI 정리의 내부 배경으로 사용할 수 있지만 이번 회차의 발언을 대신하는 근거가 될 수 없다. 여러 회차를 연결한 관찰은 근거 회차를 가지며 성격 판단, 심리 진단, 지원 지속·중단 판단은 만들지 않는다. 자동 생성은 사실의 정확성을 보증하지 않으므로 근거와 갱신 상태를 내부 계약에서 확인할 수 있어야 한다.

## 내부 구현을 선택한 이유

Honcho·Hindsight의 별도 서비스나 외부 MCP 연결을 도입하는 대신 기존 CCC 저장소, 처리 Agent와 OpenAI 연결에 기억 기능을 구현한다. 별도 서버의 설치·업데이트·백업 부담을 늘리지 않고 케이스 접근 권한, 마스킹, 감사와 보존·파기 규칙을 같은 관문에서 적용하기 위해서다. 대신 기억 추출, 갱신, 검색과 맥락 제공의 품질을 CCC가 구현하고 검증할 책임을 진다.

AI 연결과 동의·마스킹 조건이 갖춰지면 작동하는 기본 기능이며 기관은 켜기/끄기와 처리 상태를 제어한다. 기존 기관 설정 화면의 자동 기억 켜기/끄기와 처리 상태 표시는 유지한다. 이 설정은 AI 연결이나 동의 자체를 활성화하지 않는다. 기능을 끄면 기존 기억은 보존·접근 정책 안에서 유지하고 새 생성과 자동 갱신만 중단한다. 설정 값과 실행 가능 상태를 혼동해 기관 설정을 임의로 바꾸지 않는다.

## 화면 범위의 후속 결정

이번 단계에는 상담 기억 또는 현재 맥락 요약을 표시하는 새 화면, 기존 화면에 출력 문장을 삽입하는 변경, 독립 상세 화면·링크·정정 UI를 만들지 않는다. `15초 페이지`의 '오늘 만나기 전 꼭 기억할 것'과 '상담 내용 회차별 정리', '상담 기록 확인하기' 영역은 변경하지 않는다. 기존 기관 설정 화면의 자동 기억 켜기·끄기와 처리 상태 표시는 유지하며, 별도의 새 설정 화면은 추가하지 않는다.

향후 15초 페이지의 '오늘 만나기 전 꼭 기억할 것'과 '상담 내용 회차별 정리', '상담 기록 확인하기'에 상담 기억의 보조 문장을 추가할 수 있다. 어떤 영역에 어떤 근거와 문구로 추가할지는 별도 디자인 결정에서 정하며, 이 ADR은 구현된 출력 계약으로 해석하지 않는다.

시간 경과만으로 기억을 삭제하거나 해결됐다고 판단하지 않는다. 현재 중요도에 따라 내부 요약에서 물러나고 새 근거에 따라 과거 상태로 이동하며, 이력은 기존 보존·파기 규칙 안에서만 유지한다.

## 접근·안전 계약

기억 조회와 정정은 기존 케이스 상담 내용 열람 권한과 담당 실무자 권한을 따르며, 기관 설정 변경은 기관 관리자 권한을 따른다. 정정은 기대 revision을 검증하고 사람의 정정을 같은 옛 근거가 덮어쓰지 못하게 한다. 기관 기술 관리자에게 기억 본문이나 상담 출처를 새로 노출하지 않는다.

원문·기억 내용·PII·검색어와 공급자 오류 원문은 로그, 브라우저 영속 저장소, URL에 넣지 않는다. 원본 수정·철회·파기와 작업 완료가 경합할 때 늦은 결과가 최신 기억을 덮어쓰거나 파기된 기억을 되살리지 못하게 한다. 파기 시 기억 본문·이력·검색 파생물·처리 중간물을 기존 규칙에 따라 함께 제거하고 내용 없는 감사만 남긴다.
