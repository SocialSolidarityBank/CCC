# ADR-0045: 상담 기억은 승인 없는 보조 맥락으로 자동 유지한다

상태: 사용자 확정, 2026-09-08. 제품 결정은 승인됐으며 전체 구현 설계는 검토 중이다.

상담 기억은 한 사업의 케이스에 속하는 보조 맥락이다. 기록에 명시된 사실과 여러 회차를 종합한 기억 관찰을 개별 항목으로 유지하고, 그 항목에서 현재 맥락 요약을 만든다. 실무자 개인 선호나 다른 사업의 상담 기억은 합치지 않는다.

사용자는 기억의 개별 승인과 일상적인 수동 관리를 명시적으로 기각했다. 기존 공식 기록을 소급 처리하고 이후 기록·목표·액션 변경에 따라 백그라운드에서 자동 갱신한다. 사람이 필요할 때 기억을 직접 정정할 수 있지만, 정정은 읽기 중심 상세 화면의 메뉴 안에 있는 예외 조작이다. 같은 과거 근거로 정정을 되돌리지 않으며 이후 명확한 새 근거에 따른 갱신은 허용한다.

## 공식 기록과의 구분

R2의 상담 기록 승인 원칙은 유지한다. 미승인 AI 상담 초안을 기억 재료로 사용하거나 기억을 원본 상담 기록으로 승격하지 않는다. 상담 기억과 현재 맥락 요약은 별도의 자동 생성 보조 표현으로서 항목별 승인 없이 15초 페이지에 표시할 수 있다. 이는 모든 AI 산출물에 동일한 승인 절차를 적용하는 해석에 대한 명시적 예외이며, 기존 회차별 요약·대조·플래그 확정 절차를 바꾸지 않는다.

기억은 회차별 AI 정리의 배경으로 사용할 수 있지만 이번 회차의 발언을 대신하는 근거가 될 수 없다. 여러 회차를 연결한 관찰은 근거 회차를 가지며 성격 판단, 심리 진단, 지원 지속·중단 판단은 만들지 않는다. 자동 생성은 사실의 정확성을 보증하지 않으므로 근거와 갱신 상태를 확인할 수 있어야 한다.

## 내부 구현을 선택한 이유

Honcho·Hindsight의 별도 서비스나 외부 MCP 연결을 도입하는 대신 기존 CCC 저장소, 처리 Agent와 OpenAI 연결에 기억 기능을 구현한다. 별도 서버의 설치·업데이트·백업 부담을 늘리지 않고 케이스 접근 권한, 마스킹, 감사와 보존·파기 규칙을 같은 관문에서 적용하기 위해서다. 대신 기억 추출, 갱신, 검색과 맥락 제공의 품질을 CCC가 구현하고 검증할 책임을 진다.

AI 연결과 동의·마스킹 조건이 갖춰지면 작동하는 기본 기능이며 기관은 켜기/끄기와 처리 상태를 제어한다. 이 설정은 AI 연결이나 동의 자체를 활성화하지 않는다. 단순히 기능을 끄면 기존 기억은 갱신 시점을 표시해 읽을 수 있고 새 생성과 갱신만 중단한다.

## 화면과 시간

15초 페이지에는 현재 맥락 요약, 케이스별 상세에는 기억과 근거·마지막 갱신 시점, 기관 설정에는 동작 상태를 둔다. 항목마다 승인·수정 버튼을 붙이지 않으며 외부 편집기로 여는 평문 memory.md 파일은 만들지 않는다.

시간 경과만으로 기억을 삭제하거나 해결됐다고 판단하지 않는다. 현재 중요도에 따라 요약에서 물러나고 새 근거에 따라 과거 상태로 이동하며, 이력은 기존 보존·파기 규칙 안에서만 유지한다.
