# 세션 목표 기반 상담 템플릿 — AI 역할의 중심 재정의

> `yellow` **보류 중 — 2026-07-31 D52(ADR-0023)이 이 ADR의 기록지 조립 부분을 내렸다.** 상담 기록지는 고정 폼으로 가고, 확장 슬롯 `aiSchema`는 비운 채 남는다. 세션 목표·맞춤형 질문을 상담 등록 때 받는 흐름은 그대로 유효하다(D35·D43). 재개하려면 정기 상담 항목 풀을 받아 두 ADR의 보류를 함께 푼다. AI 역할의 무게중심은 이 ADR이 아니라 **브리핑 3영역(D45·ADR-0018)과 대조 3종**으로 옮겨갔다.

2026-07-17 확정. 이 제품에서 AI의 핵심 역할을 "기록의 사후 정리"에서 **"기록지의 사전 구성"**으로 확장한다. 상담 일정을 등록할 때 세션 목표와 맞춤형 질문을 먼저 받고, AI가 누적 맥락에 맞춰 **그 상담에서 꼭 기록해야 할 항목만 담은 상담 템플릿**을 구성해 준다.

배경: 기존 상담 기록지는 항목이 너무 많아 상담과 기록을 동시에 해야 했고, 그럼에도 정작 필요한 내용을 놓쳤다. 항목을 목표에 맞게 미리 줄여주면 기록이 가벼워지고, 상담은 목표에 맞는 변화를 추적하는 방향으로 흐른다.

구조:

- **세션 목표**: 이번 회차에서 다룰 것을 적는 개체. 인테이크에서 확정한 케이스 목표(D12)의 **하위 목표로 연결**된다(등록 시 케이스 목표 선택, 복수·미연결 허용). GAS는 여전히 케이스 목표에만 매긴다 — D12·GAS 이력 연속성은 그대로.
- **항목 풀**: Q(PM)가 제공하는 기본 양식. 전체 기록 항목을 펼쳐 놓고 **필수/선택으로 분류**해 둔다. 양식 팀 회신 대기(D18)는 폐기 — 항목 설계 주도권은 내부.
- **상담 템플릿**: 코어(GAS 근거·액션 아이템·리스크 플래그)는 항상 포함하고, AI가 세션 목표·질문·맥락에 따라 선택 항목을 재구성해 만든다. 상담사는 상담 전에 항목을 추가/삭제할 수 있다(AI는 제안, 최종 구성은 상담사 — R5 정신). AI 실패 시 코어만으로 된 기본 템플릿 폴백.
- 변수가 많지 않아 실제로는 상담 유형별로 템플릿이 고정 패턴에 수렴할 것으로 예상한다.

## Considered Options

- **정적 양식(외부 팀 확정) 대기**: 기존 D18 구도. 항목 과다 문제를 시스템이 물려받고 외부 일정에 종속 — 기각.
- **완전 자유 기록**: 항목 축소는 되지만 코어 수집이 불규칙해져 브리핑·통계가 무너짐 — 기각.
- **항목 풀 + AI 재구성**: 규정 필수는 지키면서 회차별 기록 부담을 최소화 — 채택.

## Consequences

- 템플릿 항목 상세와 자유도(선택 항목의 범위·개수)는 **의도적으로 미정** — Q의 기본 양식(항목 풀) 제공 후 설계. 이번 개편은 화면 플로우까지만.
- D18(양식 외부팀 경계)을 대체한다. 2단계-c(대조 프롬프트)의 선행 조건은 양식 회신에서 **항목 풀·상담 템플릿 스펙 확정**으로 바뀐다.
- 스키마 3층 구조의 "템플릿(사업 유형별 필드 묶음)"과 이름이 겹친다 — 용어집에서 상담 템플릿(회차별)과 구별한다.
- 상담 일정 등록 흐름에 세션 목표·맞춤형 질문 입력과 템플릿 미리보기/수정 단계가 추가된다(와이어프레임 반영).
