# 가명 ID를 기계 식별자·경계 통과 토큰으로 축소

2026-07-18 확정(D31). 가명 ID(동물 슬러그)의 역할을 **사람용 표시 장치에서 기계 식별자·경계 통과 토큰으로 축소**한다. ADR-0004의 화면 한글 표시("제비 003")와 A017 마이그레이션 필요성, ADR-0005의 "그 외 사용자 마스킹" 부분을 대체한다.

## 배경

가명 체계는 원래 두 가지 일을 겸했다: ① 내부 사용자에게 실명 대신 보여주는 프라이버시 장치 ② 기록·AI·통계에서 참여자를 부르는 기계 식별자. ①은 이미 두 번 후퇴했다 — 완전 가림 → 부분 노출 마스킹(구 D22) → 역할 기준 실명(D24). 이번에 Q가 남은 반쪽도 걷어냈다: **내부 사용자에게 실명을 숨기는 것은 이 단계에서 무의미하다.**

근거는 수집 정보의 성격 변화다. 참여 허들을 낮추기 위해 신청 단계에서 받는 정보를 최소화하는 방향(간편 가입 + 이름·연락처·이메일 정도)이어서, 내부 화면 노출로 인한 위험 자체가 작다. 반면 상담 내용 접근은 이미 담당 케이스 단위로 잠겨 있고(D7·D25), 진짜 위험은 **데이터가 경계를 넘을 때**(AI 전송·외부 반출)다. 한국의 CI(연계정보)처럼, 가명 ID는 그 경계에서 실명을 대신하는 안정적 토큰이면 충분하다.

## 결정

가명 ID의 살아남는 역할 4가지:

1. **DB 키·URL·참여자 구분** — 슬러그 생성 규칙(ADR-0004의 형식·의미 정보 금지 원칙)은 그대로 유지.
2. **AI 전송 시 실명 치환 앵커** — D2 2단 방어 불변. 결정론적 치환에는 안정적 가명이 필수다.
3. **외부 반출 시 대체 식별자** — 반출물(보고서·통계·CSV)에서 마스킹 옵션 4종(이름·연락처·이메일·상담 본문 내 민감 정보)을 제공하고 기본 전체 적용, 참여자 구분은 슬러그로만. 본문 민감 정보 마스킹은 D2의 2차 NER 마스킹을 재사용한다.
4. **파기 후 통계 보존의 연결 고리** — D10 불변: PII 파기 후에도 가명 기록은 통계용으로 남는다.

폐기하는 것:

- **화면 한글 표시명("제비 003")** — 화면은 실명 기본, 실명이 없을 때만 슬러그 폴백. 영↔한 매핑 레이어를 만들지 않는다.
- **내부 역할별 마스킹** — 내부 인증 사용자(관리자·상담사 전원)에게 실명 기본 표시. PII 표시 화면 조회당 감사 1건(D14)은 유지 — 추적성은 비용 없이 남는다.
- **A001 마이그레이션(CCC-archive#15)** — 기계 식별자 관점에서 형식 혼재는 무해하다(DB 제약이 양형식 허용, 운영에서 공존 실증). ID 교체는 8개 테이블 FK를 갈아끼우는 실작업이라 실익 대비 리스크가 크다.

바뀌지 않는 것: D2(AI 가명 치환), D3(금고 암호화 — 유출 시 심층 방어), D7·D25(상담 내용은 본인 담당 케이스만), D10(파기·통계 보존), D14(감사), 동의서 문안 v0(가명·위탁 서술 그대로 유효).

온보딩 원칙(간편 가입 + 최소 수집)은 이 결정의 **근거로만 기록**한다 — 카카오 등 채널 확정은 D26 법률 검토 후 별도 결정.

## Considered Options

- **현행 유지(역할별 마스킹 + 한글 표시)**: 소규모 조직에서 구분 실익이 없고, "누구를 위한 가림인가"에 답이 없다. 기각.
- **가명 체계 전면 폐기(실명 PK)**: AI 치환 앵커·통계 보존 고리·반출 대체 식별자가 사라져 D2·D10이 무너진다. 기각.
- **역할 축소(채택)**: 경계 안은 실명·경계 밖은 슬러그. 규칙이 한 문장으로 줄고, 이미 구축된 인프라(슬러그 생성·금고·감사)는 그대로 쓴다.

## Consequences

- 화면 구현: 남아 있는 역할별 마스킹 로직 제거, HERO·목록 실명 기준(슬러그 폴백) — 다음 스펙 티켓.
- CCC-archive#15 닫음(한글 표시 폐기 + 마이그레이션 불요).
- 반출 기능 구현 시 마스킹 옵션 4종 UI가 요구사항이 된다(미구현 — 향후).
- 동의서 법률 검토 시 "내부 열람 범위" 문구는 "담당자 및 배정 책임자"에서 내부 인증 사용자 기준으로 재검토 필요(D25 문구와의 정합은 그때 해소).
