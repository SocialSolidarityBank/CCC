# ADR-0017: 용어 개편 — 기관 · 실무자 · 당사자, 그리고 역할 통합(기관 관리자)

- 상태: 승인 (2026-07-28, Q — 그릴링 세션). 결정 번호 **D40**.
- 번호 이력: ADR-0016과 D39는 PR #5(참여자 초대·자기 가입, CCC-28·29)가 선점하고 있어 건너뛴다 — 그 PR은 Draft이지만 커밋에 번호가 박혀 있다.
- 관계: **CONTEXT.md 용어집의 사람·조직 축을 전면 대체**한다. D7(접근 모델)·D25(배정 책임자 PII)·ADR-0002·ADR-0005의 권한 규칙은 이름만 바뀌고 내용은 승계된다. 코드 식별자 유지 원칙은 D31(가명 ID 재정의)의 "화면 표기와 기계 식별자는 다른 층"이라는 태도를 따른다.

> **후속 대체(2026-08-22)**: 기관 관리자의 상담 내용 제한과 긴급 접근 예외는 D74 후속 개정과 ADR-0038이 대체한다. 기관 관리자는 기관 전체 상담 내용을 읽기 전용으로 열람한다.

## 배경

용어집은 2026-07-15에 "참여자"(수혜자 대체)를, 초기 설계에서 "상담사·담당자·시스템 관리자·배정 책임자"를 확정했다. 그러나 현장(사회연대은행과 향후 온보딩할 조직들)의 실제 어휘는 다르다 — 조직을 "기관", 상담 인력을 "실무자", 지원 대상을 "당사자"라 부른다. 특히 "당사자"는 복지 현장에서 자기 삶의 문제를 스스로 다루는 주체라는 관점을 담는 말로, "참여자"(사업에 참여했다는 관계만 서술)보다 제품 철학에 가깝다.

또한 역할 4개(담당자/상담사/시스템 관리자/배정 책임자)는 소규모 기관에는 과했다. 실제 운영에서 계정·설정 관리와 담당 배정은 같은 사람이 한다.

## 결정

### 1. 용어 3축 개편 (화면 표기: 기관 / 실무자 / 당사자)

| 구 용어 | 새 용어 | 화면 표기 |
|---|---|---|
| 조직 (테넌트) | **기관** | 기관 |
| 상담사 (직무) | **실무자** | 실무자 |
| 담당자 (케이스 배정) | **담당 실무자** (줄여서 "담당") | 담당 실무자 |
| 시스템 관리자 + 배정 책임자 | **기관 관리자** (역할 통합) | 기관 |
| 참여자 | **당사자** | 당사자 |

### 2. 역할 통합 — 기관 관리자

시스템 관리자와 배정 책임자를 **기관 관리자 하나로 합친다**. 기관 관리자는 계정·권한·서비스 설정·장애·보안 관리와 담당 배정·공동 담당·이관을 모두 처리한다.

권한 경계는 합치지 않고 승계한다:
- **PII(이름·연락처)**: 배정 업무에 필요하므로 열람 가능 (구 배정 책임자 규칙, ADR-0005 승계)
- **상담 내용(세션 기록·브리핑)**: 자신이 담당 실무자로 배정된 케이스만. 예외는 긴급 접근 절차뿐 (구 시스템 관리자 금지 규칙 승계 — D7 당사자 보호 원칙 불변)

### 3. 적용 범위 — 화면·문서만, 코드 식별자는 유지

사용자 눈에 보이는 모든 글자(웹 화면·테스트 단언·API 오류 메시지·주석)와 용어집·핵심 문서(CONTEXT.md·DESIGN.md·CLAUDE.md 현행 규칙부)를 새 용어로 바꾼다. **URL(`participants/`)·DB 컬럼·변수명(`beneficiaryId`, `organizationId` 등)은 바꾸지 않는다** — 열린 PR 충돌·마이그레이션·북마크 파손 비용이 표기 일관성 이득보다 크다.

## 기각한 대안

- **코드 식별자까지 전면 교체**: 일관성은 완벽하나 마이그레이션 + PR #5 전면 충돌 + 링크 파손. 기각.
- **시스템 관리자만 개명, 배정 책임자 존치**: 권한 분리는 남지만 소규모 기관에 역할 3개는 과잉. 기각.
- **기관 관리자에게 전 케이스 상담 내용 열람 허용**: 운영은 단순해지나 D7 접근 모델 붕괴 + 동의서 문안 변경. 기각.

## 영향

- 동의서 문안(§8 미결)의 열람 범위 서술은 새 역할 이름으로 재기술 필요 — "담당자 및 배정 책임자" → "담당 실무자 및 기관 관리자".
- users 테이블의 역할 값 통합(기존 두 역할 → 기관 관리자)은 별도 구현 티켓 — 이 ADR 시점에는 표기만 바뀐 상태다.
- 기존 ADR·D1~D38·STATUS 이력은 구 용어 그대로 둔다(역사 문서). 현행 용어의 정본은 CONTEXT.md.
