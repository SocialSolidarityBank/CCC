# ADR-0031: 디자인 규칙 리팩터 (D61)

- 상태: 승인 (2026-08-07 Q 지시 12건, 같은 날 구현)
- 결정자: Q
- 관련: D55(토큰 계단) · D58(리프레시 v1) · D59(카드 성격) · D60(아웃라인 카드) · DESIGN.md v3.2

## 결정 요약

색값 변경 0(pen SSOT 불변)으로, 형태·타이포·여백·컴포넌트 계약을 반복 가능한 규칙으로 닫는다.
핵심은 "같은 성격이면 같은 클래스 하나를 쓰고, 그 클래스를 고치면 전 화면이 함께 바뀐다"이다.

## 세부 결정

### 1. 버튼 직사각화 (D58 ⑥ 형태 부분 대체)

버튼 전 종류(프라이머리·세컨더리·일반·고스트·위험, 크기 2단)가 알약에서 **직사각형
radius 6**(`--radius-control`)으로 바뀐다. 입력칸(6), 카드(12)와 같은 사각 어휘라 조작
요소가 한 계열로 읽힌다. 형태 어휘는 셋으로 닫힌다:

- 누르고 입력하는 것 = 사각 radius 6 (버튼·입력칸·내비 항목)
- 읽기만 하는 배지·칩·상태 태그(2026-08-06 Q 알약 재개정) = 알약 (`--radius-pill`)
- 32px 원형 아이콘 버튼(헤더 계정 행동, 드로어 손잡이)과 라디오 = 원 (그대로 유지)

D58 ⑥ "단독 클릭 요소는 전부 알약"의 형태 부분만 대체하고, 채움(중요)과
아웃라인(일반)의 위계 원칙은 그대로다. 적용: `.wire-button`, `.page-back`,
`.month-nav-label`.

### 2. 배지 단일 계약 (WireBadge)

같은 레시피를 복사하던 8개 클래스(`.status` 계열, `.briefing-badge`, `.record-kind`,
`.record-owner`, `.record-ai-source`, `.settings-user-status`, `.onboarding-step`,
`.consent-upload-slot-state`)를 삭제하고 **`.wire-badge` + `data-tone`** 하나로 통합했다.
마크업은 WireBadge 컴포넌트(`wire-badge.tsx`)를 쓴다. 톤 5종: neutral / blue(일정·유형) /
mint(진행·담당) / lavender(AI·대기·주의) / **risk(신설 — 확인된 리스크·오류 상태 전용,
구 `.status.risk` 승계, D9 허용 자리)**. HERO 상태 태그도 `.wire-status-tag` 하나로
통합했다(`.participant-hero-stage` 는 같은 선언의 복사본이라 삭제. 형태는 2026-08-06 Q
재개정대로 배지와 같은 알약 400 이다).

### 3. 타이포 짝 계약

제목과 본문이 나뉘는 자리는 두 짝만 쓴다: 카드 제목 18/600 `--ink` + 본문 16/400
`--ink` / 소제목 16/600 `--ink` + 설명 14/400 `--sub`. 카드 안 구획 제목(h3)은 라벨이다:
14/600 으로 통일하고 색은 자리의 축을 따른다(`.wire-card-section>h3` = `--sub`,
`.record-block>h3` = 민트 deep, 2026-08-06 Q 컬러 규칙. 구 16/600 `--ink` 는 본문과
크기가 겹쳐 위계가 없었다). 제목 아래 설명(`.panel-meta`)과 자동 저장 상태는 600 에서 400 으로 내렸다.
역할표(§2-1)의 "배지·칩·메타 14/600" 행을 "배지·칩·라벨 14/600"과 "메타·설명 14/400"
둘로 갈랐다.

### 4. 카드 여백·선 규칙

- 패딩 4종으로 닫는다: 머리·행 16/24 / **본문 카드 24 사방**(구 20/24 대체 — WireCard
  실태 승격, 펼친 회차 본문과 리스크 배너를 여기 통일) / 낱개 행 카드 20/24(당사자
  카드, 2026-08-06 Q 조정값 유지) / 좁은 보조 패널 16/20(레일도 16 사방에서 통일).
- 가로 구분선은 `.wire-card-divider` 하나(회색 `--line` 1px 풀블리드).
  `.participant-card-divider` 는 같은 선언의 복사본이라 삭제.
- 세로선은 `--line` 1px 콘텐츠 높이. 새 선 스타일 금지.

### 5. 콜아웃·인용 컴포넌트 확정

- **WireCallout**(`wire-callout.tsx`): 제목 16/600 + 본문 14/400 + 행동 줄(세컨더리
  이하만)의 안내 카드. 톤 3종 = info(블루)·mint·lavender(주의·대기). risk 톤은 없다
  (리스크 어휘는 배너 전용, D9). 손 안내 상자 금지 — 구 `.note` 회색 상자를 폐지하고
  draft-notice, intake-saved-notice, 상담 등록의 인테이크 중복 경고를 이 부품으로 옮겼다.
  `.surface-card` 의 tone 에 mint·lavender tint 채움이 추가됐다.
- **WireQuote**: 기존 `.wire-quote` 계약(그라데이션 세로선 2px + 타임코드)의 부품화.
- 예시는 `/kit` 의 '콜아웃'·'인용 블록' 절.

### 6. 그라데이션 어휘 요약 승격 (값 변경 없음)

3색(블루→민트→라벤더)은 셸 프레임 라인 전용, 본문에서는 brand(선택·활성),
action(지금 정한 것), deep(컨트롤 테두리), hover(지나가는 중)의 네 가지 뜻만 갖는다.
DESIGN.md §3-3 표로 승격.

### 7. 화면 문자열 부호 청소 + 가드

남아 있던 구분자 가운뎃점(`join(' · ')` 3곳, 브리핑 처리 표시)과 긴 대시("설정 전 —
눌러서 입력" 등)를 MetaRow 조각·쉼표·괄호로 바꿨다(§10). `pnpm guard:tokens` 에 검사
2종을 추가해 결정론으로 강제한다:

- `pill-outside-badge`: `--radius-pill` 은 허용 클래스(배지·원형 아이콘·라디오·불릿)
  밖에서 위반.
- `prose-em-dash` / `prose-separator-dot`: 주석·테스트를 뺀 앱 코드의 긴 대시와
  구분자 가운뎃점.

## 왜

- 배지 레시피가 8벌로 복사돼 있어 "배지를 고치려면 어디를 고치나"가 매번 판단거리였다.
  D55 가 죽은 CSS 를 "드리프트의 저장고"라 부른 것과 같은 문제이고, 답은 삭제가 아니라
  단일 계약으로의 흡수다.
- 버튼(알약)·입력칸(사각 6)·카드(사각 12)가 세 가지 형태 어휘를 섞어 써서 화면의 사각
  리듬이 버튼에서 끊겼다(Q: "입력필드, 카드 div 와 통일감").
- 제목·본문 조합이 자리마다 달라(16/600 ink 옆에 14/600 sub) 같은 위계가 다른 옷을
  입었다. 짝을 둘로 닫으면 새 화면도 규칙에서 나온다.
