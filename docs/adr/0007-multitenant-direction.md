# 멀티테넌트 방향 확정, 구현은 단계적

2026-07-17 확정. 서비스 사용 범위를 "사회연대은행 내부 전용"(D1)에서 **여러 조직이 각자 쓰는 멀티테넌트 서비스**로 확장하기로 방향을 확정한다. 와이어프레임(CCC-wireframe)의 홈=조직 목록, 조직→사업→상담 카드 계층, 자체 로그인/가입, 참여자 초대는 이 방향의 표현이다.

단, **구현은 단계적**이다:

1. **이번 개편**: 새 IA(조직→사업→카드 선택 진입)와 화면 개편을 단일 조직 위에 구현. 인증은 Cloudflare Access 유지. 스키마의 조직 ID(D1 때 남겨둔 것)가 그대로 확장 기반이 된다.
2. **외부 조직 온보딩 직전 단계**: 이메일+패스워드 자체 인증(가입·로그인·비밀번호 찾기), 조직 단위 초대·과금·운영 모델. 별도 스펙과 보안 검토로 진행.

## Considered Options

- **내부 전용 유지(D1)**: 와이어프레임의 조직 계층·초대 흐름과 모순 — 기각.
- **이번에 인증까지 전환**: Access를 걷어내고 자체 인증 즉시 구현 — 방금 개통한 운영 인증 폐기 + 보안 설계 부담으로 7월말 일정 리스크 — 기각.
- **방향 확정 + 단계적 구현**: IA·화면은 지금, 인증·온보딩은 다음 단계 — 채택.

## Consequences

- D1을 대체한다(조직 ID 유지 결정은 이 방향의 사전 포석이었음이 확정).
- 상담사용 화면은 처음부터 "내 소속 조직의 사업 목록"을 전제로 설계한다 — 단일 조직이어도 계층 UI는 유지.
- 외부 조직 유입 전까지 공개 가입은 열지 않는다. 와이어프레임의 로그인/가입 화면은 다음 단계 스펙으로 넘긴다.
- 동의서·PII 열람 범위 문안(D25)과 감사 설계는 멀티조직 전제(조직 경계 격리)를 명시해야 한다.
