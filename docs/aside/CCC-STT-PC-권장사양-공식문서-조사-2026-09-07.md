# CCC 로컬 STT 처리 PC 권장 사양: 공식 문서 조사

- 조사일 및 공식 문서 접근일: 2026-09-07
- 목적: 현재 CCC 로컬 STT 후보를 검증할 Windows PC의 구매 기준선을 정한다.
- 범위: 공식 upstream 문서와 모델 메타데이터, 현재 저장소의 모델 고정값, S13 측정 계약만 다룬다.
- 제외: 제품 활성화, 엔진 승인, 기존 S13 기준 변경, 벤치마크 재실행은 이 문서의 범위가 아니다.

## 1. 먼저 구분할 세 가지

이 문서에서는 사양의 출처를 다음 세 종류로 구분한다.

1. **Upstream 공식 요구사항**: upstream이 설치 또는 실행 조건으로 직접 명시한 값이다.
2. **Upstream 벤치마크·참조 장비**: upstream이 특정 시험이나 예제에 사용한 장비다. 최소 사양으로 바꾸어 읽지 않는다.
3. **CCC 권장·추론**: 공식 최소 사양이 없는 부분을 현재 후보 조합, 모델 크기, S13 요구와 로컬 실패 증거를 근거로 보수적으로 정한 구매 기준이다. vendor가 발표한 최소 사양이 아니다.

이 문서의 **GPU qualification**은 고정된 모델·software 조합이 Windows 네이티브 환경에서 설치되고 정해진 입력을 처리하는지 검증하는 절차다. 제품 활성화 승인이나 현행 S13의 Windows CPU 판정을 뜻하지 않는다.

S13은 60~180초인 두 화자 합성 session 150개를 동일 장비와 동일 입력에서 측정하고, Windows CPU에서 pooled RTF `≤1.00`을 요구한다. CER, 반복률, DER, safety도 별도 고정 기준을 통과해야 한다. 미측정은 PASS가 아니다. 자세한 계약은 [`S13-pilot-metrics.md`](../specs/S13-pilot-metrics.md)에 있다.

이번 조사에서는 **보고된 로컬 CPU 전체 벤치마크 실패를 수용된 내부 증거로 그대로 받아들였으며, 벤치마크를 재실행하지 않았다.** 저장소에 남아 있는 사전 근거는 Ryzen 7 3700X 8코어, 약 24GiB RAM의 CPU 환경에서 세 후보의 단일 session smoke가 끝났지만 전체 run은 당시 `UNMEASURED`와 `full_run_incomplete`였음을 기록한다. 따라서 체크인된 사전 근거만으로 이후 실패의 세부 원인을 새로 추정하지 않는다. 근거는 [`e5-8-windows-preflight.json`](../../artifacts/pilot/e5-8-windows-preflight.json)이다.

## 3. Upstream이 실제로 발표한 내용

### 3.1 Qwen3-ASR와 Qwen3-ForcedAligner

**Upstream 공식 요구사항**

- Qwen 공식 README는 격리된 Python 3.12 환경을 예시로 제시하며, `qwen-asr` 패키지 메타데이터는 Python `>=3.9`를 요구한다. 공식 Transformers 예제는 `torch.bfloat16`과 `device_map="cuda:0"`을 사용하고, 긴 입력과 큰 batch에서 GPU 메모리를 줄이기 위해 FlashAttention 2를 권장한다. 같은 예제는 batch 상한을 낮추면 OOM을 피하는 데 도움이 된다고 설명한다. [Q1][Q2]
- Qwen 공식 모델 메타데이터는 `Qwen3-ASR-1.7B`에 BF16 parameter `2,349,217,408`개, `Qwen3-ForcedAligner-0.6B`에 BF16 parameter `917,728,896`개를 기록한다. 고정 revision의 safetensors 파일은 각각 `4,698,521,512` bytes와 `1,835,544,544` bytes이며, 합계는 `6,534,066,056` bytes, 약 `6.085GiB`다. 이는 **디스크에 저장된 가중치 파일 크기**이며 VRAM 사용량이 아니다. activation, KV/cache, CUDA·PyTorch workspace, pyannote, faster-whisper도 포함하지 않는다. [Q3][Q4][Q5][Q6]
- Qwen 공식 문서는 한국어를 ASR와 forced alignment의 지원 언어에 포함하며, forced aligner의 입력 음성 상한을 5분으로 설명한다. [Q1]

**Upstream 벤치마크·참조 장비**

- 공식 README의 로컬 예제는 CUDA GPU를 지정하고 Docker 예제도 `--gpus all`을 사용하지만, 해당 예제는 특정 GPU SKU나 VRAM 용량을 최소 사양으로 제시하지 않는다. [Q1]
- Qwen이 제공하는 `qwenllm/qwen3-asr:cu128` Dockerfile은 `nvidia/cuda:12.8.0-devel-ubuntu22.04`를 기반으로 한다. Qwen이 권장하는 FlashAttention의 공식 README는 Linux를 요구사항으로 적고, Windows는 일부 성공 보고가 있으나 compilation에 추가 검증이 필요하다고 밝힌다. 따라서 공식 CUDA 참조 경로는 Linux이며 Windows 네이티브 GPU 구성을 upstream 보장 사양으로 볼 수 없다. [Q7][Q8]

**발표하지 않은 것**

- Qwen README와 두 모델 카드·메타데이터에는 `Qwen3-ASR-1.7B + Qwen3-ForcedAligner-0.6B` 조합의 최소 CPU 코어 수, 시스템 RAM, VRAM, Windows PC 사양표가 없다. `96GB 미만이면 MAX_JOBS=4`라는 문구는 FlashAttention 2를 **빌드할 때** 병렬 job 수를 줄이는 지침이지, 추론 RAM 최소값이 아니다. Qwen의 공식 CUDA Docker image도 Ubuntu 기반이므로 Windows 네이티브 GPU 지원 최소값을 뜻하지 않는다. [Q1][Q7][Q8]

### 3.2 faster-whisper와 CTranslate2

**Upstream 공식 요구사항**

- faster-whisper는 Python `>=3.9`를 요구한다. CPU `int8`과 GPU 실행 예제를 모두 제공한다. 현재 README는 GPU 실행에 CUDA 12용 cuBLAS와 CUDA 12용 cuDNN 9가 필요하다고 명시한다. [F1]
- CTranslate2 4.8.2의 prebuilt Python wheel은 Windows `x86-64`를 지원한다. 공식 hardware support 문서는 CPU에서 SSE 4.1 이상을 지원하는 x86-64 또는 AArch64/ARM64를, GPU에서 compute capability 3.5 이상의 NVIDIA GPU를 지원한다고 명시한다. [C1][C2]
- CTranslate2 설치 문서는 Windows GPU wheel에 CUDA 12.x가 필요하다고 설명한다. 다만 같은 문서는 convolution을 쓰는 speech recognition에 cuDNN 8을 권하고, faster-whisper README는 현재 조합에 cuDNN 9를 요구한다. 공식 문서 사이에 이 차이가 있으므로, 구매 사양과 별개로 **정확히 고정된 wheel·CUDA·cuDNN 조합을 GPU qualification에서 검증해야 한다.** [F1][C2]

**Upstream 벤치마크·참조 장비**

- faster-whisper의 GPU 표는 13분 오디오와 `large-v2`, beam size 5를 CUDA 12.4와 NVIDIA RTX 3070 Ti 8GB에서 측정했다. 이 표에서 faster-whisper `int8`은 batch 없음 기준 VRAM `2,926MB`, `batch_size=8` 기준 `4,500MB`를 사용했다. [F1]
- CPU 표는 같은 13분 오디오의 `small` 모델을 Intel Core i7-12700K와 8 threads에서 측정했다. faster-whisper `int8`은 batch 없음 기준 RAM `1,477MB`, `batch_size=8` 기준 `3,608MB`를 사용했다. [F1]

**발표하지 않은 것**

- 위 숫자는 `medium` 모델, CCC의 60~180초 두 화자 fixture, Qwen·forced aligner·pyannote를 함께 쓰는 처리 Agent의 최소 사양이 아니다. faster-whisper와 CTranslate2는 이 통합 조합에 필요한 전체 시스템 RAM, VRAM, CPU 코어 수를 발표하지 않는다. [F1][C1][C2]

### 3.3 pyannote.audio

**Upstream 공식 요구사항**

- CCC가 고정한 `pyannote.audio==3.4.0` 패키지는 Python `>=3.9`, PyTorch `>=2.0.0`, torchaudio `>=2.2.0`을 요구한다. [P1]
- 3.4.0 공식 README는 `speaker-diarization-3.1`과 `segmentation-3.0`의 이용 조건 동의와 Hugging Face access token을 요구한다. GPU가 있을 때 pipeline을 CUDA device로 옮기는 예제를 제공하지만, GPU를 필수라고 쓰지는 않는다. [P2]

**Upstream 벤치마크·참조 장비**

- 현재 upstream README의 최신 open-source pipeline 속도 표는 NVIDIA H100 80GB HBM3에서 측정한 참조값이다. 이 표는 CCC가 고정한 3.4.0/`speaker-diarization-3.1`의 최소 사양이 아니며, H100 구매 요구사항으로 읽어서는 안 된다. [P3]

**발표하지 않은 것**

- 3.4.0 README와 패키지 메타데이터는 `speaker-diarization-3.1` 실행을 위한 최소 CPU 코어 수, 시스템 RAM, VRAM을 발표하지 않는다. [P1][P2]

### 3.4 Microsoft Windows 11

**Upstream 공식 요구사항**

- Microsoft가 발표한 Windows 11 설치 최소값은 호환되는 64-bit CPU 또는 SoC의 1GHz 이상 2코어, RAM 4GB, 저장장치 64GB 이상, UEFI Secure Boot 지원, TPM 2.0, DirectX 12 이상과 WDDM 2.0 driver, 대각선 9인치 초과 720p display다. Windows 11 Home과 개인용 Pro의 초기 설정에는 인터넷 연결과 Microsoft account가 필요하고, 모든 edition은 update와 일부 기능에 인터넷 접근이 필요하다. Microsoft는 개별 앱의 요구사항이 Windows 11 최소 사양을 넘을 수 있다고 함께 명시한다. [W1]

**발표하지 않은 것**

- Windows 11 최소값은 운영체제 설치 기준일 뿐 Qwen, faster-whisper, CTranslate2, pyannote 또는 CCC 처리 Agent의 실행 사양이 아니다. Microsoft는 이 STT 조합의 최소 RAM·VRAM·CPU를 발표하지 않는다. [W1]

## 4. 근거에서 CCC 구매 기준으로 넘어가는 방법

다음 판단은 모두 **CCC 권장·추론**이다.

1. CPU-only 장비는 이미 실패 증거가 있으므로 새 구매 기준의 주 처리 경로로 삼지 않는다. 다음 qualification은 NVIDIA CUDA GPU 경로를 대상으로 한다. 내부 상태는 [`e5-8-windows-preflight.json`](../../artifacts/pilot/e5-8-windows-preflight.json)과 이번 조사 입력을 따른다.
2. Qwen ASR와 forced aligner의 safetensors만 약 `6.085GiB`지만, 이는 디스크 가중치 크기이지 VRAM 실측값이 아니다. 8GB VRAM의 faster-whisper 참조 장비도 다른 모델과 workload를 측정했으므로 CCC 통합 최소값으로 재사용하지 않는다. [Q5][Q6][F1]
3. 최소 VRAM 16GB와 권장 VRAM 24GB는 고정 모델 파일의 크기, 입력 길이와 batch에 따라 달라지는 runtime memory, Windows 네이티브 실측 부재를 반영한 보수적 구매 구간이다. 두 값 모두 vendor 최소 사양이 아니며 실제 충족 여부는 GPU qualification이 결정한다. [Q1][Q5][Q6][Q7][Q8]
   - qualification 증거에는 실제 dtype, batch, 동시 session 수, 모델별 실행 device, 모델의 동시 상주 여부, peak VRAM·RAM을 기록해야 한다. 이 구매 구간 자체는 OOM 방지나 처리량을 보장하지 않는다.
   - 기존 [`CCC-상담-전사-품질-확보-검증-2026-07-12.md`](CCC-상담-전사-품질-확보-검증-2026-07-12.md)의 VRAM 12GB 안정 추정은 WSL2, 순차 실행, 청크 처리 전제의 사전 예산이다. Windows 네이티브 GPU 실측 최소값이 아니므로 이번 구매 후보 하한과 같은 등급의 수치로 보지 않는다.
4. 시스템 RAM 32GB와 64GB, SSD 512GB와 1TB도 여러 고정 model snapshot, model cache, 임시 오디오와 결과 artifact, Windows와 처리 Agent가 함께 동작한다는 CCC 운영 조건을 반영한 구매 기준이다. upstream 최소값이 아니다.
5. Windows prebuilt CTranslate2 경로가 x86-64를 명시하므로, 첫 qualification 장비는 Windows on Arm이나 NPU-only 구성이 아니라 x86-64와 NVIDIA CUDA GPU 조합으로 제한한다. Qwen의 공식 CUDA image와 FlashAttention의 공식 요구사항은 Linux를 기준으로 하므로, Windows GPU 프로필 전체가 native qualification 전까지 **CCC 잠정안**이다. [C1][C2][Q7][Q8]

## 5. CCC 최소·권장 PC 프로필

아래 표가 이 문서에서 구매 후보 수치를 정하는 유일한 표다. `최소`는 **견적과 대여·반품 가능한 검증 장비 후보를 고르는 CCC 잠정 하한**이며, upstream 보장값이나 제품 활성화 기준이 아니다. 비가역 구매 승인은 별도의 Windows GPU qualification 결과와 Q의 판단 뒤에 한다.

| 항목 | CCC 최소 프로필 | CCC 권장 프로필 | 분류와 이유 |
| 운영체제 | Windows 11 64-bit, TPM 2.0·UEFI Secure Boot 충족 | Windows 11 Pro 64-bit | OS 최소 조건은 Microsoft 요구사항이다. Pro 선택은 CCC 관리용 권장·추론이다. [W1] |
| CPU | x86-64, 8 physical cores 이상 | x86-64, 12 physical cores 이상 | **CCC 권장·추론**. CTranslate2 Windows wheel 호환성과 전처리·후처리 여유를 위한 값이다. [C1][C2] |
| 시스템 RAM | 32GB | 64GB | **CCC 권장·추론**. Qwen·pyannote·faster-whisper 환경과 cache, Windows 동시 실행 여유를 위한 값이다. |
| GPU | NVIDIA Ampere 또는 Ada 세대 CUDA GPU, VRAM 16GB 이상 | 같은 계열의 VRAM 24GB 이상 GPU | **CCC 권장·추론**. Qwen이 권장하는 FlashAttention 2의 공식 지원 세대와 디스크 가중치 크기, 미확정 runtime 여유를 반영한 잠정 구간이다. 특정 vendor 최소값이나 VRAM 실측값이 아니다. [Q1][Q5][Q6][Q7][Q8][F1][C2] |
| 저장장치 | NVMe SSD 512GB | NVMe SSD 1TB | **CCC 권장·추론**. 약 6.085GiB인 Qwen·aligner 가중치 외에 고정 model snapshot, 검증 fixture, 설치 환경, Windows update, 임시 파일과 증거를 함께 보관할 여유를 둔다. |
| 냉각·전원 | GPU와 CPU의 지속 부하를 제조사 정격 범위에서 유지하는 구성 | 장시간 지속 부하용 데스크톱 냉각과 정격 여유 전원 | **CCC 권장·추론**. 짧은 부스트 성능이 아니라 전체 S13 run을 완료해야 하기 때문이다. |
| 구매 전 확인 | CUDA 12 driver 설치 가능, CTranslate2 Windows x86-64 wheel 설치 가능 | 동일하며 고정 CUDA·cuDNN·PyTorch 조합의 사전 image 검증 포함 | 공식 Qwen CUDA 경로가 Linux이므로 Windows 네이티브 설치와 추론은 GPU qualification에서 별도로 검증한다. [F1][C2][Q7][Q8] |

qualification의 비교 조건은 합성 오디오 작업 1건을 한 번에 처리하는 단일 job으로 고정한다. 동시 job은 허용하지 않는다. Qwen, forced aligner, pyannote가 같은 시점에 GPU에 상주하는지는 실제 구현을 따르되, 각 단계의 device, dtype, batch, chunk 상한, model residency와 peak RAM·VRAM을 증거에 기록한다. 이 workload도 구매 후보 비교 조건이며 제품 계약이 아니다.

현재 benchmark-only tuple은 Python 3.12, `torch==2.9.1`, `qwen-asr==0.0.6`, `transformers==4.57.6`, `accelerate==1.12.0`이고 비교 경로는 `faster-whisper==1.2.1`, `pyannote.audio==3.4.0`이다. Windows CUDA용 PyTorch wheel, CUDA, cuDNN, CTranslate2와 FlashAttention 사용 여부를 하나의 release tuple로는 아직 고정하지 않았다. 따라서 qualification 계획은 이 tuple을 먼저 고정하고, 설치·model load·합성 5-session 실행이 OOM 없이 끝나는지와 peak RAM·VRAM·RTF를 기록해야 한다. 이 smoke는 장비 후보 적합성만 판정하며 STT 품질 통과나 제품 활성화를 승인하지 않는다.

## 6. 결론과 승인 경계

구매 후보 수치의 정본은 §5 표다. 모든 CPU core, RAM, VRAM, SSD 값은 **CCC 권장·추론**이며 Qwen, pyannote, faster-whisper, CTranslate2가 발표한 최소 사양이 아니다.

이 프로필은 **실패한 CPU 경로를 억지로 재실행하지 않고 Windows GPU 장비를 조달·qualification하기 위한 CCC 잠정 구매 기준선**이다. 공식 Qwen CUDA image는 Linux 기반이며 FlashAttention의 Windows compilation도 추가 검증이 필요하다. GPU qualification 결과는 현행 S13의 Windows CPU RTF 판정을 대체하지 않는다. 이 문서는 S13을 바꾸지 않으므로, CPU gate가 실패한 현재 상태에서는 제품 활성화가 계속 차단된다. GPU 판정으로 CPU 판정을 대체하려면 별도 spec 변경과 Q(제품 승인권자)의 승인이 필요하다. 그때까지 `sttMode=off`, `sttEngine=null`과 비활성 Local 선택지를 유지한다. 근거는 [Q7][Q8], [`CLAUDE.md`](../../CLAUDE.md), [`S13-pilot-metrics.md`](../specs/S13-pilot-metrics.md)다.
