## 0. 설계 원칙

1. **범용 코어 + 사업 유형 템플릿 2층**: 코어는 어느 기관이든 통하는 최소 공통. 특화 항목은 템플릿 층에서 켠다.
2. **우선순위 4단계로 배치가 결정된다**:
   | 순위 | 정의 | 배치 |
   |---|---|---|
   | P1 | 필수 + 중요도 높음 | 각 단계의 본문. 비면 저장 불가 |
   | P2 | 필수 + 중요도 중간 | 자동 입력·기본값으로 통과 부담 최소화 |
   | P3 | 선택 + 중요도 높음 | 마지막 단계 또는 접힘 — 조건 충족 시 강조 |
   | P4 | 선택 + 중요도 중간 | 접힘. 기본 비표시에 가깝게 |
3. **단계형 입력**: 한 페이지에 전부 펼치지 않는다. 다음→다음으로 진행하고, 진척도를 좌측(모바일은 상단)에 상시 표시. 최종 열람(완성된 기록지)은 한눈에 보이는 단일 뷰.
4. **선택지는 범용으로**: 상담 목표·지난 기록에 맞춰 동적으로 좁히는 경우가 아니면, 고정 목록으로 범위를 좁히지 않는다. 목록형 선택지에는 항상 '기타'와 자유 입력을 두고, 판단이 필요한 질문은 자유 서술을 기본으로 한다.
5. 모든 질문에 **답변거부 / 모름 / 해당없음** 허용. 등록 시 수집한 데이터는 재입력 없이 미리 채움.

## 1. 입력 플로우 — 6단계

```
① 시작(접수·참여자 확인) → ② 동의 → ③ 원하는 도움 → ④ 생활 상황
→ ⑤ 정리(목표·다음 행동 + 선택 묶음) → ⑥ 담당자 의견
```

**목표의 2층 구조 (Epic/Feature 매핑)**: 전체 상담 목표(Epic) = **케이스 목표**(goals, D12) — ⑤ 정리에서 인테이크 때 1~3개 최초 입력, 이후 수정 금지·종료+신설만. 개별 상담 목표(Feature) = **세션 목표**(D28) — 인테이크가 아니라 **상담 일정 등록 화면**에서 매 회차 케이스 목표의 하위로 연결해 입력. AI 질문·회차 템플릿(D29)은 이 세션 목표+승인된 기록을 기준으로 생성. GAS 점수는 케이스 목표에만.

좌측 스테퍼: 단계별 완료(✓)/현재/대기 + 필수 채움 카운트. 임시 저장은 어느 단계에서든 가능(수기 기록은 저장 즉시 공식, D5).

### ① 시작 — P2 중심, 빠르게 통과
| 항목 | 순위 | 입력 |
|---|---|---|
| 상담 일시·기록자·회차 | P2 | 자동 |
| 상담 방법 | P2 | 선택지(대면/전화/화상/방문/기타) |
| 참여자 정보(이름·연락처·이메일) | — | 등록 데이터 표시만(D31 실명, 재입력 없음) |
| 생년월일(달력+직접 입력, pii_vault 암호화)·거주 지역·긴급 연락처·성별 | P4 | 접힘(기본정보 더 적기) 상단. 나이 요건 사업은 템플릿이 승격 |
| 유입·의뢰 경로, 의뢰 기관·사유 | P4 | 접힘 하단(Q 지정 순서: 인적 항목 위, 경로 아래) |

### ② 동의 — 안내문 1 + 체크 최소화
**안내문 카드 1개**에 통합 고지: 수집·이용 목적과 항목, 비밀보장 범위와 한계(법정 예외), 보유·파기. "자세히 읽어보기" 아코디언으로 전문 제공.

| 체크 | 순위 | 비고 |
|---|---|---|
| 안내를 확인했으며 개인정보 수집·이용에 동의합니다 | **P1 필수** | 구 "개인정보 동의"+"비밀보장 안내 확인"을 한 체크로 통합 |
| 상담 녹음·분석과 기록의 정리·요약에 동의합니다 | **P1 필수** (Q 결정 2026-07-24, 2차: 녹음+AI 정리를 한 체크로 병합) | ⟦주의·충돌⟧ D15·D23은 "미동의여도 수기 경로 제공, 녹음/텍스트 AI **분리** 동의"가 확정 결정 — 병합·필수화 모두 충돌. **법률 검토(D15) 때 함께 판단 필요**, 확정 시 D15·D23 대체 기록. 저장 구조는 participant_consent_records 2컬럼 유지(화면 체크 1개 → 두 컬럼 동시 기록)해 되돌리기 쉽게 |

체크 2개 전부 충족해야 인테이크 성립. 타 기관 연계 동의는 인테이크에서 제거 — 의뢰·연계가 실제 발생하는 시점에 범위를 정해 받는다.

### ③ 원하는 도움 — 코어의 심장
| 질문 | 순위 |
|---|---|
| 오늘 어떤 도움을 받고 싶어서 오셨나요? | **P1** |
| 지금 가장 힘든 점 / 가장 먼저 해결하고 싶은 것은? | **P1** |
| 상황이 어떻게 달라지면 좋겠나요? | **P1** |
| 언제부터·악화 계기·오늘 정리점 (3문) | P3 (접힘 "더 묻기") |

전부 자유 서술. AI 텍스트 동의 시 요약·브리핑 소스(D15).

### ④ 생활 상황 — 6영역
영역별 **[괜찮음/긴장/위기/해당없음/답변거부] + 한 줄** = **P1**.
영역 심화(소득·부채표·주거형태 등)는 P3 — 상태 긴장/위기 또는 템플릿 설정 시 펼침. **금전지원형 템플릿 v1: 경제 심화+부채표 기본 펼침**. 심화 선택지도 범용 원칙(§0-4) 적용: 목록에 항상 '기타'.

### ⑤ 정리 — 목표·다음 행동(P1) + 선택 묶음(P3·P4)
| 항목 | 순위 |
|---|---|
| 목표 1개 이상(최대 3), 측정 가능 문장 + GAS 기준(-2~+2) | **P1** → goals(D12·D6) |
| 다음 행동(누가·무엇을) 1건 이상 | **P1** → action_items |
| 다음 만남 일시·방식 | P3 → schedules(D28) |
| **위기·안전 확인** — "지금 당장 위험하다고 느끼는 상황이 있나요?"(자유 서술) + "오늘 바로 필요한 연결"(자유 서술) + (위험 언급 시) 안전 여부·긴급 연락 | **P3** — v0.2의 필수·고정 체크 목록을 폐기(핵심 주제·상담 성격 확정 전 선택지 제시 불가, Q 피드백 ②·⑤). 생활 영역에 '위기'가 하나라도 있으면 이 블록을 펼치고 강조. 위험 내용이 기록되면 상담사가 리스크 플래그(D9) 후보로 확정 |
| 강점·자원 4문 | P3 (접힘) |
| 참여 여건 3문 | P4 (접힘) |
| 추가 확인 필요 정보 표 | P4 (접힘) |

### ⑥ 담당자 의견 — 별도 단계 (Q 2차 수정: ⑤에서 분리)
상담사의 종합 판단(참여자 발언과 구분해 기록, 자유 서술) | P3 — 마지막 단계, 접지 않고 노출

## 4. 시스템 매핑 (변경 없음)

목표→goals(GAS 기준 포함), 다음 행동→action_items, 다음 만남→schedules, 위기 기록→flags 후보(상담사 확정), 동의→participant_consent_records(필수 1종 컬럼 추가 필요), PII→pii_vault.

## 5. 남은 미결

1. **동의 안내문 전문** — 법률 검토(D15) 후 확정. 통합 안내문 구조는 `docs/consent/consent-draft-v0.md`와 정합 필요.
2. **위기 서술 → 플래그 연결 규칙** — 자유 서술에서 상담사가 플래그 유형(D9)으로 확정하는 UI는 스펙에서.
3. **구현 상세** — 단계 저장 단위(단계별 부분 저장 vs 최종 일괄), 생년월일(pii_vault 확장)·지역 컬럼, 영역 상태 저장 구조, 템플릿 설정 테이블.
4. **정기 상담 기록지** — 인테이크 확정 후 같은 방식으로 설계.
