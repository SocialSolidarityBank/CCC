# Intake 설문지: 필수 질문 vs 선택 질문

**기준**: 미국 NASW/CMSA·HMIS, 영국 Care Act 사정, 한국 통합사례관리·복지관 초기면접, 비영리 CM(Apricot/Salesforce 계열), 상담·사례관리 AI 선도(Beam/Que 등)에서 **반복되는 공통항만** 추출  
**제외**: 특정 사업(금융·노인·아동) 전용 심화 문항, 기관 커스텀 보고 필드  
**용도**: CCC 인테이크 설문지 필드 설계  
**작성일**: 2026-07-23

---

## 0. 한 줄 규칙

| 구분 | 정의 |
|---|---|
| **필수** | 첫 인테이크를 닫으려면 비어 있으면 안 되는 질문. 연속 상담·안전·계획·책무성에 직접 필요. 거의 모든 선도 체계에서 등장. |
| **선택** | 사례 복잡도·회차·프로그램에 따라 켜는 질문. 첫 회에 비워도 케이스는 열 수 있음. |

**공통 설계 원칙 (선도 수렴)**  
1. 첫 회는 **짧게 필수**, 심화는 2회차 이후 또는 영역 “위기/긴장”일 때만.  
2. 질문은 **참여자 언어**로, 코딩(영역 코드·우선순위)은 뒤에서.  
3. **답변거부 / 모름 / 해당없음**을 필수로 허용.

## 1. 필수 질문 항목 (Core)

아래는 “질문 문장” 단위입니다. UI에서는 한 블록으로 묶어도 됩니다.

### A. 케이스·접촉 메타 (상담사 기입 포함)

| # | 질문/항목 | 왜 공통 필수인가 |
|---|---|---|
| A1 | 오늘 상담(접수) 일시는 언제인가요? | 모든 기록 체계의 기본 키 |
| A2 | 상담 방법은 무엇인가요? (대면/전화/화상/방문 등) | 채널·동의 범위·안전 |
| A3 | 담당 상담사(기록자)는 누구인가요? | 책임·권한 |
| A4 | 어떻게 이 기관/서비스를 알게 되었거나 의뢰되었나요? (유입·의뢰 경로) | HMIS/통합사례/복지관 공통 |
| A5 | (해당 시) 의뢰 기관·의뢰 사유는 무엇인가요? | 연계 연속성 |

### B. 동의·권리 (인테이크 성립 조건)

| # | 질문/항목 | 왜 공통 필수인가 |
|---|---|---|
| B1 | 서비스 목적·비밀보장 범위(한계 포함)를 안내받았나요? | NASW/IOM/Care Act/한국 실무 |
| B2 | 개인정보 수집·이용에 동의하나요? | 법적·실무 전제 |
| B3 | (사용 시) 녹음·음성 분석에 동의하나요? | 분리 동의 표준 |
| B4 | (사용 시) 기록의 AI 정리·요약에 동의하나요? | 선도 AI 제품 공통 전제 |
| B5 | 필요 시 다른 기관에 정보 연계하는 것에 대한 동의 범위는? | 의뢰 가능 조건 |

> B는 “설문 본문” 앞단 게이트. 미동의하면 심화 질문·AI 경로를 열지 않음.

### C. 호소·원하는 도움 (인테이크 심장 — 최강 공통)

| # | 질문 문장 (권장 표현) | 선도 공통 의미 |
|---|---|---|
| C1 | **오늘(지금) 어떤 도움을 받고 싶어서 오셨나요?** | presenting request |
| C2 | **지금 가장 힘든 점 / 가장 먼저 해결하고 싶은 것은 무엇인가요?** | primary need / priority |
| C3 | **상황이 어떻게 달라지면 좋겠나요?** (원하는 변화·성공 모습) | person-centred outcome |
| C4 | **이런 어려움은 언제부터 시작되었나요?** | onset |
| C5 | **최근에 상황이 더 어려워진 계기가 있었나요?** | precipitating event |
| C6 | **이번 상담을 마칠 때, 무엇이 정리되면 좋겠나요?** | session/intake goal |

이 6개는 Beam 사정 초안, Care Act outcomes, NASW assessment, 한국 초기면접 “주호소·희망서비스”, Salesforce person-centred intake에서 **가장 겹치는 코어**입니다.

### D. 생활 영역 — “상태”만 필수 (상세 서술은 선택)

영역 이름은 기관마다 달라도, **상태를 묻는 것**은 공통입니다.

각 영역마다 필수 질문 형태는 동일:

> **[영역]에서 지금 괜찮음 / 긴장 / 위기 / 해당없음 / 답변거부 중 어디에 가깝나요?**  
> (한 줄) **짧게 설명한다면?**

| # | 영역 | 최소 필수 질문 |
|---|---|---|
| D1 | 경제·생계 | 생활비·소득·미납 등으로 지금 얼마나 힘든지 |
| D2 | 주거 | 지낼 곳·유지 가능성이 안정적인지 |
| D3 | 일·고용·학업 (해당 인구) | 일/학업 상태가 안정적인지, 최근 변화 |
| D4 | 건강(신체) | 일상에 지장 주는 건강 문제가 있는지 |
| D5 | 심리·정서·스트레스 | 최근 마음의 어려움이 일상에 영향을 주는지 |
| D6 | 가족·관계·돌봄 | 지지/갈등/돌봄 부담이 있는지 |

**필수인 것**: 영역별 **상태 코드 + 한 줄**  
**필수가 아닌 것**: 영역별 장문 조사, 금액 전수, 진단명, 상세 병력

### E. 안전·위기 (짧고 필수)

| # | 질문 문장 | 비고 |
|---|---|---|
| E1 | **지금 당장 위험한 상황인가요?** (주거 상실 임박, 폭력, 자해·타해 위험, 긴급 생계 등 — 기관 정의 체크) | 통합사례 위기도, Care Act safeguarding 인접 |
| E2 | **오늘 바로 연결이 필요한 도움이 있나요?** | 긴급 경로 |
| E3 | (해당 플래그 시) **지금 안전한가요? 긴급 연락할 사람이 있나요?** | 최소 안전계획 입구 |

길지 않게. 3문항 이내가 선도 실무 패턴.

### F. 강점·기존 자원 (강점모델·Care Act·한국 사정 공통)

| # | 질문 문장 |
|---|---|
| F1 | **지금까지 이 상황을 버틸 수 있었던 힘·강점은 무엇인가요?** |
| F2 | **이미 해본 대응이나 시도가 있나요?** |
| F3 | **의논하거나 도움을 요청할 수 있는 사람·기관이 있나요?** |
| F4 | **현재 이용 중인 서비스·지원·제도가 있나요?** (이름만) |

“문제 목록만 있는 인테이크”는 레거지. 선도는 F를 필수로 올리는 쪽.

### G. 참여 여건·연락

| # | 질문 문장 |
|---|---|
| G1 | **앞으로 상담·지원에 참여할 때 어려울 수 있는 점은 무엇인가요?** (시간, 이동, 돌봄, 비용, 수치심 등) |
| G2 | **연락 가능한 시간대와 연락 시 주의할 점이 있나요?** |
| G3 | **선호하는 연락·상담 방식은 무엇인가요?** |

### H. 목표·다음 행동 (인테이크 종료 시 필수)

| # | 질문/항목 |
|---|---|
| H1 | **앞으로 함께 다룰 목표를 한두 문장으로 정한다면?** (1~3개) |
| H2 | **다음으로 누가 무엇을 할지** (참여자 / 상담사 / 외부 연계) |
| H3 | **다음 만남 또는 다음 연락은 언제·어떤 방식으로?** |

계획 없는 인테이크는 선도 CM에서 “미완성 사정”에 가깝습니다.

### I. 식별·연락 (최소 PII)

| # | 항목 | 비고 |
|---|---|---|
| I1 | 이름(또는 표시명 정책) | 필수 |
| I2 | 연락처(전화 등 1개) | 필수 |
| I3 | 생년월일 또는 연령대 | 대체로 필수(연령 민감 프로그램은 연령대만) |
| I4 | 거주 지역(시군구 수준) | 서비스 관할·연계용 최소 |

## 2. 선택 질문 항목 (Optional)

첫 회 필수 아님. **영역 상태가 긴장/위기이거나, 2회차+, 프로그램 특화**일 때.

### J. 기본정보 확장

| 항목 | 켤 때 |
|---|---|
| 이메일 | 비대면·문서 송부 |
| 상세 주소·방문 경로 | 가정방문 |
| 성별/성정체성/호칭 | 당사자 요청·서비스 관련 시 (기본 선택) |
| 가구 형태·동거인 목록 | 가구 단위 사례 |
| 비상 연락처 | 위기·의료 인접 |
| 언어·통역 필요 | 의사소통 장벽 |
| 법적 대리인·보호자 | 미성년·후견 |

### K. 영역 심화 (상태 “긴장/위기”일 때만)

| 영역 | 선택 질문 예 |
|---|---|
| 경제 | 월소득 구간, 고정지출 항목, 수급·차상위 여부, **부채 원장 표** |
| 주거 | 점유형태, 보증/월세, 퇴거 통보, 주거 환경 |
| 고용 | 직장/고용형태, 근로시간 변화, 구직 의지 |
| 건강 | 진단·복약·치료 공백 이유, 장애 등록 |
| 심리 | 수면·식사·외출, 표준 척도(PHQ-9 등), 과거 상담·입원 |
| 가족·돌봄 | 돌봄 대상, 학대·갈등 상세, 가계도/생태도 |
| 법률·신용 | 소송·회생·파산·체납 상세 |
| 교육·사회참여 | 학교·고립·여가 |

### L. 이력·맥락 심화

| 항목 | 켤 때 |
|---|---|
| 생애 주요 사건 타임라인 | 복합·장기 사례 |
| 이전 기관 이용 **결과**(성공/실패/대기) 상세 | 연계 설계 |
| 트라우마·학대 상세 | 동의·안전 확보 후, 전문 경로 |
| 문화·종교·정체성 관련 필요 | 맞춤 개입 |
| ADL/IADL | 노인·장애·돌봄 |
| 보호자·가족 욕구 사정 | whole-family / Care Act carer |

### M. 측정·도구 (기관 정책이 있을 때만)

| 항목 |
|---|
| PHQ-9, GAD-7 등 스크리닝 |

| 위기도 점수 전체 문항지 |
| 만족도·준비도(동기) 척도 |

### N. AI·미디어 관련 (동의한 경우만)

| 항목 |
|---|
| 녹취 전문 보관 여부 |

## 3. 필수 vs 선택 한눈에

```
[필수 코어]
동의 게이트
식별·연락 최소
유입 경로
C: 원하는 도움 / 가장 힘듦 / 원하는 변화 / 시작·악화 / 오늘 정리점
D: 6영역 상태코드 + 한 줄
E: 위기 2~3문
F: 강점·시도·지지망·이용 중 서비스
G: 참여 장벽·연락 주의
H: 목표 1~3 + 다음 행동 + 다음 연락

[선택 확장]
상세 PII, 영역 심화 표, 부채 원장 전항목,
생애사, 가계도, 심리척도, 법률 상세, AI 부가지표
```

## 4. 첨부 CCC 초안과의 매핑

| 첨부 초안 섹션 | 판정 |
|---|---|
| 0. 기본정보 (이름·연락·상담일·담당·회차·방법·유입·연락주의) | **필수** (이메·성별은 선택) |
| 1. 기관을 찾게 된 이유 1–6 | **필수** (C 블록과 일치, 우수) |
| 2. 생활상황 영역별 상세 질문 | **상태+한 줄 = 필수**, 금액·부채 표 전항목·장문 = **선택(심화)** |
| 부채 기록표 | 금융·복합 사례에서 **강력 권장 선택** → 경제 영역이 위기면 사실상 준필수 |
| 3. 원하는 도움 | **필수** |
| 4. 강점과 자원 | **필수** |
| 5. 상담 참여 여건 | **필수** |
| 6. 추가 확인 | **선택 프레임** (표 자체는 유지, 행은 케이스별) |
| (초안 약함) 동의·위기·목표 확정·다음 액션 | **필수로 신설** |

## 5. 설문지 배치 권장 (선도 UX)

1. **동의** (B)  
2. **지금 필요한 도움** (C1–C3)  
3. **위기** (E) — 초반에 두어 위험 시 경로 분기  
4. **맥락** (C4–C6)  
5. **영역 상태** (D) — 카드형, 긴장/위기만 심화 펼침  
6. **강점·자원** (F)  
7. **참여·연락** (G)  
8. **목표·다음 행동** (H)  
9. (접힘) 심화 선택 세트 (K–M)

## 6. 필수 질문 “최소 문장 세트” (복붙용)

상담사가 입으로 묻거나 폼에 그대로 쓸 **최소 세트**:

1. 오늘 어떤 도움을 받고 싶으신가요?  
2. 지금 가장 힘든 것은 무엇인가요?  
3. 어떻게 달라지면 좋겠나요?  
4. 언제부터였고, 최근에 더 나빠진 일이 있었나요?  
5. 경제·주거·일·건강·마음·관계 중 지금 빨간불인 곳은 어디인가요? (각 한 줄)  
6. 당장 위험한 상황인가요? 오늘 바로 필요한 연결이 있나요?  
7. 버팀목·강점, 이미 해본 것, 도움 받을 사람/기관은?  
8. 상담에 나오기 어려운 조건·연락 시 주의할 점은?  
9. 앞으로의 목표 한두 가지와, 다음에 누가 무엇을 할까요?

이 9축이 선도 서비스 인테이크의 **공통 필수 교집합**입니다.  
그 밖의 상세 표·척도·생애사는 전부 **선택 확장**으로 두면 됩니다.
