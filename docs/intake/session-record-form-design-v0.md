# CCC 기본(정기) 상담 기록지 설계 v0.1 (초안)

> **전제**: 인테이크 기록지 설계 v0.3(`intake-form-design-v0.md`)의 원칙을 그대로 계승 — 범용 코어 + 사업 유형 템플릿 2층, 우선순위 P1~P4, 단계형 입력 + 진척도, 선택지 범용 유지, 답변거부/모름/해당없음 허용.
> **정기 상담의 차별점**: 인테이크가 "기준선을 세우는" 기록이라면, 정기 상담은 **"기준선 대비 변화만 기록"**하는 기록. 이미 시스템에 있는 것(세션 목표·미해결 액션·지난 요약·GAS 이력)은 다시 쓰지 않고 불러와 확인·갱신한다.
> **관련 결정**: D5(수기=즉시 공식), D6(GAS는 상담사), D9(플래그), D12(목표 종료+신설), D28(세션 목표), D29(회차 템플릿 — AI 재구성 항목이 들어오는 곳이 바로 이 기록지)
> **상태**: draft · 2026-07-24 · 브랜치 docs/session-record-form

---

## 0. 인테이크와의 관계

| | 인테이크 (1회차) | 정기 상담 (2회차~) |
|---|---|---|
| 목적 | 기준선(Baseline) 수립 | 기준선 대비 **변화** 기록 |
| 케이스 목표(Epic) | 최초 입력 (1~3, GAS 기준) | 표시만 — 필요 시 종료+신설(D12) |
| 세션 목표(Feature) | 없음 | 일정 등록에서 연결된 것 **표시**(D28) |
| 생활 6영역 | 전 영역 상태+한 줄 | **변화 없음 원클릭**, 변한 영역만 갱신 |
| GAS | 기준(-2~+2 정의)만 | **점수를 매기는 곳** (상담사 직접, D6) |
| 동의 | 게이트 (필수) | 없음 — 등록 시 1회로 완료, 변경 시에만 |
| 필수(P1) | 동의·호소 3문·6영역·목표 | **오늘 상담 내용(수기 메모) 사실상 하나** |

## 1. 화면 구조 — 원페이지 스키밍 + 아코디언 (v0.2, Q 피드백 2026-07-24)

인테이크(6단계 위저드)와 달리 정기 상담은 **오늘 상담 내용을 빨리 보는 것**이 핵심 — 단계 분할 대신 "한 번에 보는 범위"를 원페이지로 확대한다.

```
[고정 헤더 — 스크롤해도 항상 위에 박힘]
  이번 상담 목표(세션 목표, D28) + 전체 목표(케이스 목표) 참조 ← 모든 기록의 기준점. 화면 표기: "이번 상담 목표" / "전체 목표 N"

[스키밍 본문 — 위에서 아래로 훑는 순서 = 우선순위 순서]
  1. 오늘 확인할 질문 (체크리스트 — 브리핑 질문 + 맞춤 질문)
  2. 오늘의 상담 기록 (수기 메모, P1 유일 필수 — 펼쳐진 상태)
  3. 미해결 액션 (항목별 체크박스 + 한 줄 기록 폼)
  4. 생활 변화 확인 (6영역 압축 행 — "변화 없음" 기본, 델타만 갱신)

[아코디언 — 필요할 때만 펼쳐 기록]
  5. 목표 평가(GAS) — 권장
  6. 회차 템플릿 항목(D29) — 템플릿
  7. 새 액션·다음 만남 — 선택
  8. 위기·안전 확인 — 선택(영역 '위기' 시 자동 펼침+강조)
  9. 리스크 플래그 수기 추가 · 목표 종료+신설 — 조건부

[마무리 — 항상 노출]
  10. 담당자 의견 (P3, 참여자 발언과 구분)
```

배치 원칙(Q 피드백 ③): **필수·중요도 높음이 위, 선택·중요도 낮음이 아래** — 스크롤 순서 자체가 P1→P4 순서다. 진척도는 우측 레일의 필수 채움 카운트로 표시(위저드 스테퍼 폐기).

### ① 시작 — 전부 자동/표시, 입력 0에 가깝게
| 항목 | 순위 | 입력 |
|---|---|---|
| 상담 일시·기록자·회차(N)·방법 | P2 | 자동(일정 연동) |
| 오늘의 세션 목표 | — | **표시**(일정 등록에서 연결, D28) — 없으면 "미연결" 표시 + 여기서 추가 가능 |
| 지난 상담 한 줄 요약·미해결 액션 개수 | — | 표시(브리핑 요약) — 참고용, 클릭 시 브리핑 이동 |

### ② 지난 확인 — 미해결 액션 점검
| 항목 | 순위 | 형식 |
|---|---|---|
| 미해결 액션 아이템 각각의 처리 | P1 (항목별 원클릭) | **완료 / 진행 중 / 못 함 / 보류** + (선택) 한 줄 — action_items 갱신 |
| 지난 상담 이후 달라진 일 | P3 | 자유 한 줄 |

미해결 액션이 0건이면 이 단계는 자동 통과(표시만).

### ③ 오늘 상담 — 기록지의 심장
| 항목 | 순위 | 비고 |
|---|---|---|
| 오늘 상담 내용(수기 메모) | **P1 — 이 기록지의 유일한 실질 필수** | 자유 서술. 저장 즉시 공식 기록(D5). 녹음 병행 시 AI 정리는 별도 승인 경로 |
| 오늘 확인할 질문(AI 생성+맞춤 질문) | — | 접힘 참고 패널 — 브리핑의 질문을 그대로 표시, 체크하며 진행 |
| **회차 템플릿 항목(D29)** | P3 | AI가 세션 목표·맥락 기반으로 재구성한 선택 항목이 여기에 들어옴. 상담 전 수정 가능, AI 실패 시 코어만(폴백). v0에서는 자리 구조만 — 항목 상세는 D29 보류 범위 |

### ④ 변화·평가 — 델타 기록
| 항목 | 순위 | 형식 |
|---|---|---|
| 생활 6영역 변화 | P1 (원클릭 가능) | 기본값 **"변화 없음"** — 변한 영역만 눌러 상태 재선택+한 줄. 인테이크 상태가 옆에 표시(예: 경제 위기 →) |
| GAS 점수 | P3 (권장) | 케이스 목표별 -2~+2 선택(기준 문구 표시) + 근거 한 줄. **상담사 직접**(D6, AI는 근거 발췌 제안만). 매 회차 강제 아님 — 매기면 추이에 쌓임 |
| 목표 종료+신설 | P4 (조건부) | 목표 달성·폐기 시: 종료 사유 기록 + 새 목표 신설(D12). 문구 수정 금지 안내 |

### ⑤ 정리 — 다음으로 연결
| 항목 | 순위 |
|---|---|
| 새 액션 아이템(누가·무엇을) | P3 — 정기 상담에서는 권장(없는 회차도 있음) |
| 다음 만남 | P3 → schedules(세션 목표 연결 안내) |
| 위기·안전 확인 | P3 — 자유 서술 2문, ④에서 '위기' 선택 시 자동 펼침+강조(인테이크 v0.3과 동일) |
| 리스크 플래그 수기 추가 | P4 — 고정 유형(D9) 선택+근거. AI 제안 플래그의 확정은 검토·승인 화면 몫 |

### ⑥ 담당자 의견 — 별도 단계 (인테이크와 동일)
상담사의 종합 판단, 참여자 발언과 구분해 기록. P3, 접지 않고 노출.

## 2. 필수/우선순위 요약

```
[P1 — 이것만 채우면 저장 성립]
미해결 액션 처리(항목별 원클릭, 0건이면 통과)
오늘 상담 내용(수기 메모)
6영역 변화 확인("변화 없음" 원클릭 허용)

[P2 — 자동]
접수 메타(일시·기록자·회차·방법) · 세션 목표 표시 · 지난 요약 표시

[P3 — 권장·조건 강조]
지난 이후 변화 한 줄 · 템플릿 항목(D29) · GAS 점수+근거 · 새 액션 · 다음 만남 · 위기·안전

[P4 — 접힘·조건부]
목표 종료+신설 · 플래그 수기 추가
```

## 3. 시스템 매핑

수기 메모→sessions(즉시 공식, D5) / 액션 처리·신설→action_items / 6영역 델타→sessions 스키마(저장 구조는 스펙에서) / GAS 점수+근거→goals·gasEvidence / 목표 종료·신설→goals(D12) / 위기 서술→flags 후보 / 다음 만남→schedules(D28) / 템플릿 항목→ai_schema 확장 슬롯(D29, 통계 제외).

## 3.5 에이전트 역할 점검 (Q 질문 ④: 체크사항·질문·중요도 분류를 AI가 할 수 있는가)

| 작업 | 가능 여부 | 근거·조건 |
|---|---|---|
| 오늘 확인할 질문 생성 | **가능 — 이미 설계됨** | D22·D29: 승인된 기록 기반 질문 2~3개 생성이 브리핑 스펙. 세션 목표(D28)가 입력으로 들어가면 질문이 목표에 정렬됨. R2 제약: **승인된 기록만** 입력으로 사용 |
| 상담 체크사항(확인 항목) 생성 | **가능** | 미해결 액션·지난 대조 3종(미논의 목표 포함)·세션 목표에서 결정론+AI 혼합으로 도출 가능. 액션 기한·미논의 목표는 코드로, 맥락형 체크는 AI로 |
| 회차 템플릿 항목 재구성 | **가능 — D29 그 자체** | 항목 풀(필수/선택 분류 확정본)에서 AI가 세션 목표·맥락 기반 재구성. 항목 풀 확정이 선행 조건. 실패 시 코어 폴백 |
| **중요도(P1~P4) 분류** | **AI 초안 가능, 확정은 사람** | 코어 필수(P1·P2)는 기관·시스템이 고정(AI 변경 불가), AI는 **선택 항목(P3·P4) 안에서의 우선 배치만** 제안. R5(AI 금지 영역)와 정합: 기록 구조를 AI가 확정하지 않고 상담사가 상담 전 수정 가능(D29와 동일 원칙) |
| 플래그·GAS | **제안까지만** | 확정 금지(D6·D9·R5) — 기존 결정 그대로 |

결론: **4개 작업 모두 에이전트 수행 가능하되, "AI는 재구성·제안, 필수 코어와 확정은 시스템·상담사"** 경계(D29·R5)를 유지하면 된다. 선행 조건은 항목 풀 확정과 승인된 기록 축적(콜드스타트 시 질문 품질 낮음 — 세션 목표·액션 기반 결정론 체크가 폴백).

## 4. 미결

1. **6영역 델타의 저장 구조** — 회차별 스냅샷 vs 변경분만: 스펙 티켓에서.
2. **GAS 입력 주기 정책** — 매 회차 권장 vs 월 1회 등 기관 설정: 템플릿 층 후보.
3. **템플릿 항목 상세(D29 보류 범위)** — 항목 풀 전체 확정 후.
4. **녹음 병행 UI** — 녹음 시작/업로드가 이 기록지에 붙는지, 일정 카드에 붙는지: 스펙에서.
5. 시안: `artifacts/session-record-form-mockup-d30.html`
