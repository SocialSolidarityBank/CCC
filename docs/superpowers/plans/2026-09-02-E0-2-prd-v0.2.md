**Goal:** Publish a product-language PRD that translates ADR-0041 D76~D83 into complete requirements for Community Cloud, Local Single, and Local Office.

**Architecture:** The PRD keeps deployment mode, storage, and AI choice as separate product decisions while documenting the shared core experience. **Tech Stack:** Markdown, product requirements, ADR-0041/0042 decision records.

**Spec:** `CCC_OPEN_PILOT_PLAN.md` E0-2, `docs/adr/0041-one-core-three-deployment-modes.md`, `docs/adr/0042-supabase-read-only-preflight.md`, and `/Users/seongqkim/developer/PROJECTS/CCC-new/inbox/CCC-open-pilot-v0.2.md`.

## Global Constraints

- Community Cloud, Local Single, and Local Office are all formal implementation modes and use one common core, screen set, API, permission model, audit model, privacy gates, and AI material contract.
- Storage mode and AI mode are independent. STT choices are `off`, `local`, and `azure`; LLM choices are `off` and `openai`.
- STT is `off` immediately after installation in all three modes. Before STT-G1~STT-G3 and Q approval, `sttEngine` is `null` and `faster-whisper` is not automatically selected.
- AI processing requires one institution-controlled Processing Agent PC in every deployment mode.
- OpenAI receives only the Agent/core-validated AI Packet and uses `store:false`; unmasked source text and original audio never go to OpenAI.
- Azure Speech receives original audio only after an explicit Azure STT choice and valid consent for that external voice processing, through the Seoul endpoint. The PRD must not claim that original text never leaves the institution in all circumstances.
- Community Cloud original audio is temporarily held only in institution-owned Supabase private Storage, retained through the next business day’s first Agent processing opportunity, deleted immediately after processing, and deleted with administrator incident state 24 hours after first availability if still unprocessed.
- There is no seven-day or 30-day Community Cloud audio default.
- Manual notes are official records immediately when saved and are not approval-pending. AI drafts remain non-official until approved.
- The six consent areas, seven fail-closed codes, seven runtime ports, D84 read-only preflight, and D83 installation/backup/rollback rules remain aligned with the ADRs.
- This branch changes only `PRD/CCC-open-pilot-v0.2.md` and this ticket-local plan. No ADR, root plan, implementation file, inbox file, GitHub/Linear state, or external service is changed.
