# 작은 근거 꺽쇠와 일정 목표 폭 맞춤 설계

- 상태: 승인 (2026-09-01, Q 선택)
- 범위: 15초 페이지의 `근거 인용 보기`, 상담 일정 등록의 `세부 목표 연결`

## 배경

두 자리가 이미 있는 공용 규칙에서 벗어나 있었다.

1. `근거 인용 보기`는 14px 요약 줄인데 기본 32px 원형 화살표를 쓴다. 같은 크기의 좁은 행인 세부 목표와 등록 동의 `자세히 읽어보기`는 24px 작은 원과 compact 꺽쇠 잉크를 쓴다.
2. 상담 일정 등록의 `세부 목표 연결` 선택창은 데스크톱에서 `max-width: 320px`로 막혀 있다. 같은 목표 묶음의 `세션 목표 1` 입력창은 반복 행동 버튼 열을 제외한 496.5px다. 390px에서는 두 입력창이 이미 293px로 같다.

## 결정

### 1. 근거 인용 보기

`WireSourceQuotes`의 공용 `.wire-card-arrow`에 기존 작은 변형을 적용한다.

- 컨테이너: `data-size="sm"`, 24px
- 잉크: `data-glyph="compact"`, 기준 글자 `.7em`
- 방향: 닫힘은 아래, 펼침은 위
- 광학 기준: 중심 오차 0.5px 이하, 잉크 비율 0.45 이하

새 클래스, 새 크기 토큰, 화면 전용 꺽쇠를 만들지 않는다. `WireSourceQuotes`를 쓰는 15초 페이지, 리스크 배너, 승인 검토, 회차 카드도 같은 근거 인용 부품이므로 함께 작은 변형으로 통일한다.

### 2. 세부 목표 연결 선택창

데스크톱에서는 선택창의 오른쪽 끝을 `세션 목표 N` 입력창의 오른쪽 끝에 맞춘다.

- 목표 묶음 전체 폭에서 반복 행동 버튼 열 32px과 열 간격 12px을 뺀 폭을 선택창에 적용한다.
- 값은 기존 토큰 `--pill-height`와 `--space-3`으로 계산한다.
- 767px 이하에서는 세션 목표 입력창과 선택창을 모두 전폭으로 둔다.
- 현재 1280px 하니스 기준 기대 폭은 선택창과 세션 목표 입력창 모두 496.5px이다.
- 현재 390px 하니스 기준 기대 폭은 둘 다 293px이다.

선택창을 카드 전체 폭으로 늘리지 않는다. 데스크톱에서 반복 행동 버튼 열보다 44px 길어져 두 입력창의 오른쪽 선이 다시 어긋나기 때문이다. 고정 px 폭도 쓰지 않는다.

## 검증

`pnpm design:align`의 실제 부품 하니스에 다음 계약을 추가한다.

1. `근거 인용 보기`의 닫힘과 펼침 꺽쇠는 24px 원 안에서 중심 오차 0.5px 이하, 잉크 비율 0.45 이하이다.
2. 상담 일정 등록의 `세부 목표 연결` 선택창과 `세션 목표 1` 입력창은 1280px과 390px에서 같은 폭이다.
3. 390px에서 두 입력창과 반복 행동 버튼에 가로 넘침이 없다.

기존 토큰, 정렬, 위계 가드와 웹 테스트를 함께 통과해야 한다. 실제 프리뷰에서는 두 폭에서 닫힘과 펼침을 확인하고 콘솔 오류와 페이지 오류가 없어야 한다.
