# 사업 등록 폼, 사업 도입 확인 화면 설계 (design-lane 1단계)

- 상태: 배치표 초안 (2026-09-07 그릴링, 결정은 ADR-0045 D87. 검수 후속 6건은 ADR "Q 확인 대기"에 기본값 있음)
- 범위: 사업 등록 폼의 라디오 2구획(저장 위치, 처리 경로), `확인하는 법` 링크, 관리자 확인 체크, 설정 화면의 `설정 필요` 배지
- 구현 소유: `design-adjustments` 워크트리(디자인 소유 잠금). 이 문서는 `docs/public-project-admission` 레인이 썼고 화면 코드·DESIGN.md·시안은 손대지 않았다
- 1차 대상: Community Cloud. Local 두 모드는 끝의 축소표
- 입력: ADR-0045(이 PR), `DESIGN-RULES.md`, `skill://design-lane`, 선행 배치표 `2026-09-06-onboarding-invite-admin-screens-design.md` 화면 2(기관 초기 설정)

## 전제

- 규칙은 `DESIGN-RULES.md`가 갖는다. 단 번호 ①~⑧은 그 §1 표다
- 부품은 `apps/web/app/components/wire/` 현행 것만 쓴다. 새 부품 0, 새 클래스 0, 새 토큰 0, 새 색 0을 목표로 한다
- 화면 문자열은 ADR-0045 "확정 문안 v1"을 그대로 쓴다. 문안을 바꾸면 ADR이 새 버전과 sha256을 발행한다. 문안 사본을 이 문서에 두지 않는다
- 화면 문자열에 긴 대시와 구분자 가운뎃점(공백 있는 ` · `)을 쓰지 않는다(`guard:tokens`). `local`, `off` 같은 코드 식별자를 화면 문자열에 노출하지 않는다
- 이 화면은 결정을 저장할 뿐 잠금을 구현하지 않는다. `나중에 정하기`·미확인 상태의 차단은 API 거부(E9-3 계열)이고 화면 숨김이 아니다

한 카드 안 구획 셋과 마지막 체크다. 카드 안 카드 금지이므로 구획은 `WireCardSection`으로 가르고 구분선은 부품이 붙인다.

| 1 | 사업 표시 이름 | ②/⑥ | `SearchInput` | 기관 초기 설정 2단계와 같은 칸 |
| 2 | 사업 유형 배지 `금전지원형 v1` | 배지 | `WireBadge` neutral | 고정, 선택 없음(`program_type`은 이 축과 별개) |
| 3 | 구획 라벨 `데이터 저장 위치` | ② | `WireCardSection` label | Community Cloud 설치에서만 렌더(ADR 결정 4) |
| 4 | 폼 머리 안내 "이 설치는 기본형입니다. 다른 저장 위치는 설치를 따로 해야 합니다." | 콜아웃 | `WireCallout` tone=info | 구획 첫 줄 |

| 9 | 구획 라벨 `녹음과 AI 정리` | ② | `WireCardSection` label | |
| 10~12 | 라디오 3개: 외부 업체 처리 허용 / 기관 안에서만 처리 / 나중에 정하기. 각 라디오 아래 조건 설명 한 줄 | 선택지 14/600 + ⑦ | `WireChoice type="radio"` × 3, 설명 ⑦ | 기본 선택 없음 |

| 11a | 기관 안 아래 고정 문구(수기 경로 고지) | ⑦ | `.wire-form-hint` | STT-G1~G3 승인 뒤 문안 버전이 바뀐다 |
| 13 | `확인하는 법` | 링크 | 줄 8과 같은 링크 | |

## 화면 B. 기관 초기 설정 2단계 (첫 사업)

선행 배치표 화면 2의 2단계(사업 표시 이름 + 유형 배지) 아래에 화면 A의 줄 3~17을 그대로 붙인다. 부품·문안·조건 동일. 단계 완료 버튼은 기존 `다음`이고 `사업 등록` 버튼은 없다. 초기 설정에서 `나중에 정하기`로 넘어가면 사업은 만들어지고 화면 C에 `설정 필요` 배지가 뜬다.

## 화면 C. 설정 화면의 사업 목록 (`/admin` 기관 탭, 새 구획)

| 줄 | 무엇 | 단 | 부품 |
| --- | --- | --- | --- |
| 구획 | 라벨 `사업` + `사업 등록` 버튼 | ② + 버튼 | `WireCardSection` label, `WireButton` secondary |
| 행 | 사업 표시 이름 ① + 상태 배지 + 저장 위치·처리 경로 값 ④ | ①·배지·④ | `WireItem` title / status / description |
| 배지 | `설정 필요` | 배지 | `WireBadge` neutral. 두 축 중 하나라도 `나중에 정하기`이거나 확인이 없거나 무효화된 경우 |
| 배지 | `확인됨` | 배지 | `WireBadge` neutral. 확인이 유효한 경우. 상태 낱말은 본문 글자로 두지 않는다(§1) |
| 행동 | `수정` | 14/600 계열색 | `WireItem` action → 화면 A 수정 모드 |

배지는 제목 글자 바로 뒤에 붙는다(2026-09-04 전역 기준). 배지 유무와 무관하게 줄 높이 22를 예약한다.
