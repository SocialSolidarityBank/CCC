# 일정 화면 통합 설계 (다가오는 일정 + 전체 일정 → `일정`)

- 상태: 승인 (2026-08-23, Q 그릴링 6문 + 시각 시안 1회)
- 대체하는 것: D21 의 2섹션 화면과 D54 의 별도 전체 일정 화면이라는 "두 화면" 전제. 구현 시 새 D번호와 ADR 로 기록하고 CLAUDE.md·DESIGN.md 해당 절을 같은 커밋에서 개정한다.
- 유지하는 것: CCC-66(오늘 묶음은 상태를 거르지 않음), CCC-57(앞으로 올 날짜는 예정만), D47·D54(완료 회차는 상담 기록 앵커, 그 외는 브리핑), D35(사이드바=장소 / 우상단=행동), D7(권한은 게이트웨이).

## 1. 결정 요약 (그릴링 확정)

| # | 질문 | 확정 |
| --- | --- | --- |
| 1 | 첫 질문은 무엇인가 | 오늘과 다음 상담이 먼저. 지난 일정은 보조 |
| 2 | 지난 일정 전환 방식 | 한 화면 안 범위 전환 `다가오는 7일 \| 월 전체` |
| 3 | 이름 | 사이드바·페이지 제목 모두 `일정` |
| 4 | 목록 구조 | 날짜별 펼침. 일정이 있는 날짜만 그림 (시각 시안 A) |
| 5 | 가장 가까운 상담 강조 | 그라데이션 아웃라인만, 배지 없음 |
| 6 | 월 전체 구조 | 같은 날짜별 펼침을 1일→말일 순으로, 오늘 제목 강조 |

## 2. 정보 구조

- 사이드바 메뉴 `다가오는 일정`·`전체 일정` 두 개를 **`일정` 하나**로 합친다 (`app-sidebar.tsx` `programMenu`).
- 경로는 `/programs/:type/schedule` 유지. 범위는 쿼리 `?range=`(기본 `week`, `month`)로 남아 새로고침·공유에 유지된다.
- `/programs/:type/schedule/all` 은 `?range=month`(month 쿼리 보존)로 **리다이렉트만** 남긴다.
- 제목 아래 범위 전환은 사각 radius 6 두 개, 선택 = `--gradient-action` 면(정한 것 어휘), 비선택 = 흰 면 + `--line` 1px.

## 3. 다가오는 7일 (기본 범위)

- 데이터: 현행 `getUpcomingSchedules`(오늘 + 7일 창) 재사용. 새 SQL 0.
- 일정이 있는 날짜만 `8월 23일 오늘 · N건` 제목으로 펼치고 아래에 현행 `ParticipantCard` 를 그대로 나열한다. 빈 날짜는 그리지 않는다.
- 날짜 판정은 서버가 준 `board.date` + 기관 시간대(`orgDateKey` 패턴) — 브라우저 시간대 금지.
- 상태 규칙: 오늘 묶음은 끝난 상담도 완료·취소·불참 배지와 함께 남는다(CCC-66). 내일 이후 묶음은 예정만(CCC-57).
- **가장 가까운 상담**(오늘 이후 첫 `scheduled` 건) 카드 한 장만 `--gradient-brand` 아웃라인. 배지는 붙이지 않는다.
- 7일 안에 일정이 0건이면 빈 상태 계약(WireEmpty 어휘) + 상담 등록 버튼.

## 4. 월 전체

- 데이터: 현행 `getMonthSchedules(month?)` 재사용.
- 같은 날짜별 펼침을 1일→말일 순으로. 지난 일정에는 상태 배지, 이번 달이면 오늘 날짜 제목을 강조한다.
- 이전 달·다음 달 이동은 이 범위에서만 표시. `?nav=2` 시안 스위치는 제거하고 확정 시안 하나만 남긴다.
- 빈 달은 현행 빈 상태 계약(달 이동 링크 유지) 그대로.

## 5. 이동·행동·정리

- 카드 이동: 완료 회차 → `/records#record-{sessionId}`, 그 외 → 브리핑 (현행 `rowHref` 통일).
- 우상단 행동: `당사자 등록` + `상담 등록`(프라이머리) 유지.
- **시간순 정렬 토글 삭제** — 날짜별 묶음이 순서를 이미 말하고, 역순 토글은 묶음 제목과 충돌한다.
- 삭제·대체: `schedule/all/page.tsx`(리다이렉트로 대체), `schedule-cards.tsx` 의 오늘/다가오는 2구획 구조(날짜별 묶음으로 대체).
- 테스트: 두 화면 테스트를 통합 화면 기준으로 재작성 — 상태 거르기, 기관 시간대 자정 경계, 사업 유형 거르기, 리다이렉트(구 경로·month 보존), 가장 가까운 카드 강조 1장뿐, 월 이동 해 경계, 빈 상태.

## 6. 하지 않는 것

- 새 SQL·마이그레이션·새 색·새 그라데이션 0.
- 필터 없음(D54 유지 — 범위 전환이 곧 필터).
- 날짜 띠·달력 격자 없음(그릴링 4·시각 시안 C 기각).
- `다음 상담` 배지 없음(그릴링 5 B 기각 — 한 카드 배지 2개는 소음).
