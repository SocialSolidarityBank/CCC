# 15초 페이지(브리핑) 요구사항 (구 CLAUDE.md §6)

> 2026-09-26 분리: 원문은 `CLAUDE.md` §6 에 있던 내용을 그대로 옮겼다. 판정 우선순위와 인용 규칙은 `CLAUDE.md` 가 정한다.

> **2026-08-08 Q 용어 개편**: 화면 이름 '상담 준비' → **'15초 페이지'**, HERO 프라이머리 '상담 시작' → **'상담 기록'**, 일정 화면 이름 '상담 일정' → **'다가오는 일정'**. 모든 화면·문구에 통일 적용. 아래 본문의 구 용어는 결정 당시 기록이다.
>
> **2026-09-04 Q 용어 개편 2차**: 기록을 쓰는 자리는 **'상담 기록하기'**, 쌓인 기록을 읽는 자리는 **'상담 기록 확인하기'**다. 구 '상담 기록'(HERO 프라이머리·작성 화면 제목)과 구 '전체 상담 기록'(목록 화면 제목·이동 버튼)이 서로 헷갈려 이름 자체를 동사로 갈랐다. '전체 상담 기록으로 돌아가기'처럼 목적지 이름에 동작을 덧붙이던 라벨도 목적지 이름 하나로 줄인다.

**2026-07-29 D45로 전면 재구성** (ADR-0018) — D43의 재설계 봉인이 이 결정으로 풀렸다(CCC-15 착수 가능). 한 화면, 스크롤 최소, 15초 훑기는 불변.

화면 골격(위에서 아래로):

1. **HERO 카드** — 유지 (D37·D38, `ParticipantHeroCard`). 이름 + 상태 태그 + 메타 한 줄, 우상단 행동 최대 2개. 가명 ID는 15초 페이지에 반복하지 않고 당사자 정보 허브의 정보 격자에서만 보인다(2026-09-02 Q 부분 개정). 상세 DESIGN.md §5
2. **리스크 경고 배너** — 유지: 확인된 플래그가 있을 때만 HERO 바로 아래, 접힘 불가 (D9)
3. **전체 목표 카드** — 카드형 한 줄로 방향 표시(점수·게이지 없음, D43). 비어 있으면 "설정 전" + **그 자리에서 바로 입력·수정**(**담당 실무자만** — 2026-08-22 Q 후속 개정으로 구 기관 관리자 수정 권한 대체) — 첫 상담에서 당사자와 대화로 정한 뒤 바로 적는 흐름(D43 미결 해소). **2026-08-09 D62 개정**: 주 입력 자리는 인테이크 기록 화면으로 옮기고 이 카드는 보조 입력·수정 자리다. 카드 아래에 활성 세부 목표를 기본 펼침 최대 3줄로 표시한다(ADR-0032)
4. **영역 ① 오늘 만나기 전 꼭 기억할 것** — 구 '지난 상담 브리핑'·'오늘 확인할 질문' 카드를 대체. **실무자 입력(세션 목표·맞춤형 질문)이 위, AI 제안이 아래**. AI 제안은 최대 3개, 각각 **짧은 제목 + 확인 이유 + 근거 회차/원문 링크** 필수(근거 없는 항목 금지). 재료는 공식 기록만(수기 메모 + 승인된 AI 정리, R2)
5. **영역 ② 상담 내용 회차별 정리** — 회차마다 한 줄: **상담일 · 상담 유형 · 핵심 한 줄**. 유형은 현행 2종(인테이크/기본 상담)으로 시작, 세분 유형(초기상담·사정·개입 등)은 §8 미결과 함께. 핵심 한 줄은 AI가 만들고 승인 흐름에서 함께 승인(R2), 승인 전·녹음 없음이면 수기 메모 앞부분 + '수기' 배지(D5). '승인 대기 N건' 배지는 이 영역 머리
6. **영역 ③ 내용 불일치** — 회차 간 불일치 + 회차 내 모순. **AI는 판단하지 않고 양쪽 원문 인용 + 회차 링크만 나란히**(R5). 검출은 기록 공식화 시점(수기 저장·AI 승인)에 실행·저장, 브리핑은 저장된 결과만 읽는다. 처리 3종(**상황 변경/기록 오류/확인 완료**)은 표시일 뿐 **원본 불변** — '기록 오류' 처리 시 해당 기록 옆에 처리됨 표시만. **2026-08-22 후속 개정**: 기관 관리자는 읽기 전용이고, 처리는 담당 배정된 케이스의 실무자만 한다. 전건 감사(D14), 처리 항목은 접힌 이력으로 보존
7. **미해결 액션 · 개인정보 카드** — 유지 (개인정보는 역할 기준 직표시, 감사 조회당 1건 — D24, ADR-0005)
8. **`자세한 상담 기록 보기`** — 맨 아래 한 줄, 전체 상세 기록의 입구 (D37)

GAS 아코디언은 코드에서 제거한다(D43 이행 — 스키마·데이터는 유지). 감정은 추이 지표로만 표시한다. 레이아웃 수치는 D37 계약을 따른다.

`yellow` **아직 없는 것**: **추가 정보(확장 슬롯 자동 생성 필드)** 는 **보류**다 — 기록지가 고정 폼이 되어 조립할 것이 없다(D52·ADR-0023). **Q 입력 대기가 아니다**: 항목 풀 미결은 2026-07-31 해소됐고(8장), D29를 재개할 때 함께 푼다. **상담 유형 세분화는 여전히 8장 미결**이다.
